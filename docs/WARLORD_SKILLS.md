# 武将30人：v21の役割別スキル

部隊用と塔用のパッシブは配属先で切り替わります。得意兵種では説明に記載した追加効果が働きます。武将ID・レア度・所持枚数・画像・保存形式は維持しています。

## 対応範囲

今回の役割別パッシブ・必殺技は、防衛戦の塔と路上部隊向けです。同時期にmainへ追加された攻城戦は、従来の攻撃・防御の武将補正を維持します。攻城戦の専用必殺技は既存の実装を維持します。保存や死亡・負傷・攻城編成の処理は維持しています。

## 共通ルール

- 秀吉は回復役へ変更したため、補充・修理割引は廃止。領土の割引と輝元の兵站割引は維持します。
- 最大HP増加は現在HPを増やしません。解除・交代時には新しい上限で制限し、再配属で無料回復できません。
- 回復支援は衛生兵の通常回復に適用し、必殺技や継続回復を増幅しません。同じ支援は重複しません。兼続と秀吉の回復量は乗算（1.3×1.2）、回復間隔も乗算（0.8×0.7）です。
- 氏康の盾は発動時の生存者だけが対象。8秒経過・解除・移動・ウェーブ終了で消えます。近接・遠距離とも軽減後のダメージを吸収します。

- 必殺技は戦闘中にボタンを押すと対象を自動選択して発動します。対象選択画面や自動一時停止はありません。発動できる対象がいなければ再使用待ちは消費せず戦闘を続けます。
- 攻撃は射程内で城に近い敵を優先し、治療は範囲内でHP割合が最も低い生存兵・塔を選びます。救援は傷ついた部隊、救護陣は傷ついた部隊付近、攻撃陣は敵付近の道を自動選択します。入口・城直前・部隊の重なりなど移動先の制限を維持します。
- 技の威力は、塔では現在の攻撃力、部隊では生存兵の攻撃力合計の半分（衛生兵は回復量の2倍を攻撃力として換算）が基準です。
- 再配属は発動中の技を終了しますが、再使用待ち・初撃済みの敵・追加射撃カウント・割引券・追加ゴールド上限をリセットしません。発動済みの毒や敵の弱体は規定時間だけ残ります。
- 致命傷防止は発動時点の生存者だけが対象。戦死・全壊後の復活はありません。
- 毒は重ねず威力と持続の最大値を更新。弱点・集中砲火による被ダメージ増加は合計35%まで。複合の被ダメージ軽減は最大65%。
- 移動先は道に補正し、入口・城の直前・他部隊と重なる位置を拒否。移動前に足止めを解除します。敵の押し戻しもそれぞれの進行ルートに沿って行います。
- 氏康の足止め上限+1は、元から足止め可能な兵種が対象です。敵騎兵を止められるのは味方騎兵だけです。足止め上限の増加や突破保護の解除でもこの制限は変えません。
- 輝元の兵站割引は次の準備時間の治療・修理のどちらか1回。重複せず、次のウェーブ開始で失効します。配属を変えても重複取得できません。
- 防御無視を実際の効果にするため、敵に防御値を導入。通常攻撃での実効耐久が以前と同じになるよう生成時のHPも補正しました。
- 戦闘効果・再使用待ちは停止中・説明画面・ウェーブ間では進まず、x2を共通の時間で反映します。
