# 戦場試練（v107試作・v107.1で戦闘を進化・v108で広い戦場と兵士の操作・v108.1でサバイバル）

最大5人の育成済み兵士を1人ずつ出撃させる、少人数の個人戦です。メニューの「⚔️ 戦場試練」から始めます。**正式な仕様ではありません。**今はステージ「三方の関」の1つだけです。

- 防衛戦・修練場・攻城戦・全国制覇とは別のモードで、それぞれの戦闘処理（`tick`・`tickBattle`）には組み込んでいません。
- 修練場は、これまでどおり経験値・熟練度を育てる場所です（置き換えていません）。

## 遊び方

1. 「⚔️ 戦場試練」で、出撃する兵士を最大5人選ぶ（保存済みで生存している兵士だけ）。
2. 「出撃（配置へ）」→ 光っている場所（関の手前の広場）をタップして、1人ずつ配置する。「🧭 自動で並べる」も使える（近接が前、遠距離・衛生兵が後ろ）。
3. 「⚔ 戦闘開始」→ あとは自動。兵士はそれぞれ自分で敵を探して戦う。
4. 終わり方は4つ。
   - 勝利：敵を全滅させた
   - 敗北：味方が全滅した
   - 撤退：「↩ 撤退」を押した
   - 時間切れ（敗北）：300秒たった。衛生兵だけで出撃した場合などに、終わらなくならないようにするため
5. 結果の画面に、勝敗・撃破数・生存者・戦死者（仮）・兵士ごとの撃破と回復を出す。

戦闘中のボタンは「↩ 撤退」だけです。防衛戦のウェーブ開始・部隊・建設・編成のボタンは隠し、修練場・攻城戦も始められません。

## 兵士の行動（AI）

| 兵種 | 行動 |
| --- | --- |
| 近接（足軽・槍兵・騎兵など） | 一番近い敵を狙い、届く所まで近づいて斬る。騎兵は新しい敵への最初の一撃が強い（突撃） |
| 遠距離（弓兵・鉄砲兵など） | 射程に入るまで近づいて撃つ。近接の敵に射程の45%より近づかれたら、関の方へ少し下がる |
| 衛生兵 | HPの割合が一番低い味方へ近づいて回復。けが人がいなければ、前で戦う味方の少し後ろについていく |
| 敵 | 道を進み、兵士に気づいたら（190以内）その兵士を狙う。合流点を過ぎた敵はどこにいる兵士でも狙う。遠距離の敵（弓）は射程で止まって撃つ |

- 狙った敵が倒れるまで同じ敵を狙い、倒れたら次に近い敵へ替えます。
- 兵士どうし・敵どうしは近づきすぎると押し合い、完全には重なりません。
- **能力**：本番の兵士の能力を読んで使います。
  - 能力値・職業・装備・スキル（`soldierStats`・`unitOf`・`skillSum`）。
  - 攻撃のダメージは防衛戦と同じ式です（敵の防御、防御無視、大将狙い、突撃）。
  - 受けるダメージも防衛戦と同じ式です（兵士の防御、受けるダメージ軽減、遠距離軽減、騎兵の槍の弱点）。一撃は最大HPの6割までです。
- **使わないもの**：職業の技（JOB_ACTIONS）・閃き・伝説の奥義・3回ごとの技・武将の必殺技は、まだ使いません（基本の動きを確かめてから）。

## 三方の関（マップ）

- 上（北の道）・中央・下（南の道）の3本の道から敵が出て、関の手前の合流点で1本になります。
- 合流点の先に味方の配置場所（石畳の広場）があり、その奥に城（関）があります。
- **出現**：15組・26体。北・中央・南から順に出て、最後に中ボスが来ます。
- **敵の強さ**：出撃した兵士の平均Lvの0.7倍の敵Lvで、修練場と同じ強さの表を使います。攻撃は個人戦向けに0.55倍です。
  - 装備なしの同じLvの5人（近接2・遠距離2・衛生兵1）で、Lv10〜400 は1〜2人倒れながら勝てる程度です。
  - Lv1500 では負けました。
- **マップと戦闘処理を分けてある**：`TRIAL_MAPS` に道・合流点・配置場所・城・出現の順番を書きます。ほかのステージや洞窟は、マップのデータを足して同じ処理（`tickTrial`）で動かします。
- 背景は、新ドット絵の素材（木・岩・城）を使って描きます。従来版の絵では簡単な木と櫓を描きます。

## 安全（試作）

- 兵士は「試練の兵」（HP・位置・攻撃の待ちだけを持つ写し）として戦い、本番の兵士は読むだけで書き込みません。
- **戦死は仮**です。本番の兵士は失われず、英霊名鑑に載らず、戦歴・経験値・熟練度も変わりません。
- 報酬・経験値・熟練度はありません。
- 兵士・武将・奥義書などの保存データを1つも書き換えません（試験で、戦場試練の前後で全部の保存データが同じことを確認）。
- 戦場試練の途中で再読み込みすると、戦闘は続きません（何も保存していないため）。
- **本番にするとき**：`endTrial` の結果を本番の戦死処理（`recordDeath`）へ渡す入口を1か所に置き、`TRIAL_RULES.real` で切り替える形にしてあります（今は `false`）。

## v107.1 の変更（戦闘の進化）

### 画面
- 戦場試練の間は、防衛戦の城HP・ゴールド・ウェーブ・配置数の表示を隠します。
- 戦場の上の帯と下の帯に、次の4つを出します。
  - ステージ名
  - 味方（生存数）
  - 残り敵数
  - 経過時間
- ボタンは「↩ 撤退」だけです。
- （v108 で変更）兵士をタップすると、その兵士を操作します。下の「v108 の変更」を見てください。

### 職業技・閃き
- 防衛戦・攻城戦と同じ処理（`evolutionAction`）を、戦場試練用のつなぎ（`trialEvolution`）で使います。
  - 技の発動条件・待ち時間・効果は既存のままで、新しい技は足していません。
  - 共通の待ち（3秒）と技ごとの待ちで、二重発動・無限発動しません。
- 職業技は、兵士の今の職業と熟練度の段階（`jobActionStage`）で決まります。
- 閃きは、兵士が覚えて装備しているもの（`insightOf(s).equipped`）だけが発動します。
- 戦場試練に合わせたこと：
  - 「足止め中の敵」は「自分を狙って近くにいる敵」として扱います。
  - 「同じ部隊の味方」は出撃した全員として扱います。
- 技の待ち・盾などの戦闘中の値は、本番の兵士を元にした「写し」に書きます。本番の兵士・保存データは変わらず、経験値も入りません。
- 一撃の倍率も防衛戦と同じです：大将狙い・居合・一閃・装備の会心など・騎馬の上級職。
- 職業技・閃きの盾は兵士のまわりの輪で出し、受け流しも効きます。
- 強い技（上位の職業技・閃き）だけ、兵士の上に技名を出します。

### 敵の強さ（戦力の評価）
- **敵Lv** ＝ 平均Lv（150を超えた分は伸びをゆるめる）× 0.7 × 強さの比 ^0.3
  - 強さの比：同じLvの素の兵士と比べて、職業・装備・スキル・能力の書で何倍強いか。1〜3倍に収めます。
- 職業・装備で強くなった分は、敵にはその一部だけ反映します。強くなった分の大半は兵士の有利になります。
- **出撃人数**：人数が少ないと、敵の体力・攻撃と、ふつうの敵の数を減らします。5人で全部、3人で約8割です。
- **低Lv**：平均Lv40未満では、敵の体力・攻撃を最大45%下げます（育て始めでも挑戦できる）。
- 比べた結果（自動の試験）：

| 編成（5人） | 敵Lv | 結果 |
| --- | --- | --- |
| Lv5・基本職・装備なし | 4 | 勝ち（1人倒れる） |
| Lv60・上級職・装備あり | 44 | 勝ち（1人倒れる） |
| Lv60・基本職・装備なし | 42 | 負け（終盤まで粘る） |
| Lv300・最上級職・装備・閃き | 157 | 勝ち（全員生存） |
| Lv300・基本職・装備なし | 149 | 勝ち（2人倒れる） |
| Lv1500・最上級職・装備・閃き | 388 | 勝ち（全員生存） |
| Lv60・3人（上級職・装備） | 44（敵21体） | 勝ち（2人生存） |

### 敵の行動
- 狙う兵士は「近さ」に「すでに狙われている数」を足して選びます。1人に集まりすぎず、衛生兵は少しだけ後回しです（最優先にはしない）。
- 遠距離の敵は、近づかれると少し下がって射程を保ちます。
- 盾兵（PR #127）が前に立ちます。後ろの鉄砲足軽は、盾兵の陰から撃ちます（盾兵の近くでは受けるダメージ ×0.4。技の貫通は抜ける）。
- 動こうとしているのに3秒ほとんど進まない敵は、次の目印へ進めます（道や地形に引っかかって止まらない）。

### 演出
- 近接は斬撃、弓は矢、鉄砲は銃煙と弾、回復は回復の光、敵を倒すと小さな爆発。中ボスは大きな爆発と「中ボス撃破！」です。
- 強い技だけ技名を出します。画面全体の閃光・振動は使いません。
- 演出の数には上限があります（effects 80・shots 160）。60を超えると細かい演出を省きます。

### 結果の画面
- 兵士ごとに出すもの：名前・職業・Lv・撃破・与えたダメージ・回復量・使った職業技／閃き（技名×回数）・生存（HP）／仮の戦死。
- 与えたダメージ・回復・撃破からいちばん活躍した兵士に「🏅 活躍」を付けます。
- 経験値・報酬・戦歴は本番のデータに入れません。

## v108.1 の変更（サバイバル：主人公1人＋仲間4人）

試作です。数値（敵の数・強さ・時間）は、実機のテストプレイで見直します。三方の関（配置して守る遊び方）はそのまま残し、出撃の画面で遊び方を切り替えます。

### 主人公の選び方
- 「☰ メニュー」→「⚔️ 戦場試練」→ 上の「🔥 サバイバル」を押す。
- 兵士を最大5人選ぶ。選んだ兵士が「👑 主人公：」の下に並ぶ。
  - 1人を押して主人公にします（どの職業でも。最初は1人目）。
  - 戦闘の前なら何度でも変えられます。
- 「🔥 N人でサバイバル開始」。配置はなく、すぐ始まります。
- 主人公の育成データは作りません。兵士の職業・装備・閃きをそのまま使います（写しで戦う仕組みは v107 と同じ）。

### 操作
- 主人公は左下のスティックで8方向（その間の向きも）に歩きます。PC は WASD・矢印キーでも動かせます。
  - 歩く速さは三方の関の1.3倍です（敵の群れから逃げ回れるように）。
- 指を離すと止まります。止まっている間も、通常攻撃・回復・職業技・閃きは自動で続きます。
- カメラは主人公を追います。
- 戦闘中は主人公を変えません。兵士の札と「全員自動」は出しません（戦場を広く見せるため）。
- 右下は、Phase 4.2 の手動の奥義ボタン用に空けています。

### 仲間（AI）
- 仲間は、主人公のまわりの持ち場（前後左右の4か所）を基準に動きます。
  - 主人公が動くと持ち場も動き、ついてきます。
- 持ち場から 230 までの敵を、自分の役割どおりに倒します（v107.1 の AI と同じ処理）：
  - 近接は斬り、槍兵は前で受け止めます。
  - 弓兵・鉄砲兵は射程を保って撃ちます。
  - 衛生兵は、けがをした仲間（主人公も）を回復します。
- 持ち場から 300 より離れたら、敵より主人公のそばへ戻るのを優先します（追いかけすぎて孤立しない）。
- 戻るときは少し速く歩きます（1.3倍）。
- 木・岩は、すぐ先にあれば横へまわってよけます。川は橋を通ります（敵も同じ）。
- 引っかかって8秒戻れないときは、主人公の近くへ合流させます（試作の安全策）。

### 敵の出現と強さ
- 敵は、主人公から見て**画面の外**（少し先）に、まとまって出ます。
  - 目の前には出ません。
  - 川・木・岩の上には出ません。
  - できるだけ主人公と同じ川の側に出ます。
- 敵ははじめから兵士を追いかけます。歩く速さは三方の関の0.75倍で、主人公より少し遅めです（狼は速い）。
- 時間とともに増えます。
  - 出る間隔：2.6秒 → 2.0秒。
  - 1回に出る数：1体 → 2体（60秒）→ 3体（120秒）。
  - 種類：足軽だけ → 狼・槍兵 → 弓兵（遠距離）が混ざる。
- 時間とともに強くなります。強敵が出る頃に、体力 1.8倍・攻撃 1.6倍です。
- 敵1体は弱め（三方の関の0.12倍の体力）で、たくさん倒せるようにしています。
- 敵の Lv は、三方の関と同じ決め方（出撃する兵士の Lv・職業・装備）です。
- 出撃の人数が少ないと、出現の間隔をのばします（三方の関と同じ割合）。
- 同時にいる敵は**36体まで**（iPhone の重さ）。
- 主人公から 1100 より遠くなった敵は、主人公の近くの画面の外へ移します（遠くに溜まらない）。
- **2分30秒で強敵（大将）**が出ます。
  - 体力は大将の表の0.6倍で、5人で20〜30秒ほどで倒せます。
  - 強敵が出たあと、ふつうの敵は3秒ごとに1体だけになります。

### 勝ち負け
- 強敵を倒すと勝利。
- 主人公が倒れたら敗北です。仲間が倒れても、主人公が生きていれば続きます。
- 強敵を倒せないまま5分たつと時間切れ（敗北）。
- 「↩ 撤退」で途中でやめられます。
- 結果の画面：
  - 撃破数・強敵（撃破／健在／未出現）・時間。
  - 兵士ごとの活躍（主人公に👑）。

### 画面
- 上の帯：残り時間（強敵が出たら ⚠強敵）・撃破数・仲間の生存人数。
- 左上：主人公のHPの棒。
- 戦場の下：主人公の名前・HP・スティック・撤退。
- ミニマップと、画面の外の敵の印（強敵は大きい印）は v108 と同じです。

### 3分間の戦闘の例（シミュレーション）
- Lv300 の5人（剣聖・槍将・弓聖・銃将・医王）、主人公が止まったまま：3分2秒〜3分22秒で勝利。
  - 撃破 約125〜130。
  - 同時の敵は最大25体ほど。
- 主人公が敵から離れたり戻ったりする場合も勝利（3分18秒〜3分26秒）。
- Lv60 の5人もほぼ勝利。
- Lv5 の5人・Lv60 の3人は、勝ったり負けたりの手ごたえです。
