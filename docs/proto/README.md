## 統一したルール

- **輪郭**：1ドットのこげ茶の輪郭線を、すべての素材に付ける。
- **光**：上からの光で、明・中・暗の3段の色を使う。
- **味方と敵**：味方は藍、敵は赤。具足と背旗（さしもの）の色で区別する。同じ絵の色だけを替える。
- **兵種の見分け**
  - 足軽：陣笠と刀
  - 槍兵：赤い兜（金の前立て）と長槍
  - 弓兵：茶の陣笠・弓・矢筒
  - 鉄砲兵：黒い陣笠と鉄砲（撃つと火）
  - 衛生兵：白い頭巾・杖・薬箱（赤十字は使わない）
  - 騎兵：馬と兜の乗り手
- **大きさ**：兵士は20×24ドット。iPhoneの戦場では1ドットが約2.4画素になり、高精細の描画（v104.4）でくっきり表示される。

## 組み込む場合の進め方（承認後）

1. 兵士の描画（`unitFigure` など）を、試作の素材を使う形に差し替える。
   - 今の絵は残し、メニューで「新しいドット絵」を選んだときだけ使う形から始める。
2. 上級職・最上級職は、基本の兵種の絵に兜・武器・色の差分を重ねて作る。
3. 塔の強化Lv（1〜5）、敵の兵種（大将・特別な敵・名将）、被弾・戦死のコマを追加する。
4. 素材は1枚のスプライトシートにまとめ、`assets/manifest.json` から読む（容量と読み込み回数を抑える）。
