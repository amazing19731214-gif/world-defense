# サバイバル：十種の巨大ボス

サバイバルの3面ごとに、専用の姿と予告付き特殊攻撃を持つ大ボスが出現します。通常の大将が出る面も含め、面クリア後の宝箱と次の面への進行は既存の仕組みを使います。

推奨Lvは育成の目安です。Lvによる挑戦・撃破の制限は設けず、装備・職業・仲間・その回の強化や操作も勝敗に影響します。最終ボスはLv1から育てた5職編成（成長B、装備・奥義なし）を使い、サバイバルLv41・攻撃系の通常宝箱4個を含む条件で調整しました。同じ条件でLv300・600は敗北、Lv1000は約123秒で撃破しました。最終ボス単体の比較で、道中や報酬の抽選を含む通しプレイではありません。

## 巨大化と攻撃予告

大ボスの本体は登場順に大きくなり、10体目が最大になります。33面以降は終焉の覇王が3面ごとに再登場し、大きさは同じまま、面数に応じて能力が上がります。

特殊攻撃は円・直線・輪などの危険範囲を先に表示します。主人公が危険範囲の中にいる場合は、移動速度に応じた回避猶予を確保します。同じ特殊攻撃の範囲が重なっても、一人に重複して命中しません。

## 30面のプチエンディング

30面で終焉の覇王を倒すと、その挑戦で一度だけ「十の巨影を越えて」の案内を表示し、**「ここから先はおまけです。」**と伝えます。

- **宝箱へ進む（続行）**：30面の宝箱を受け取り、兵士・仲間・強化を引き継いで31面以降へ進めます。
- **ここでクリアする（結果へ）**：勝利として終了し、結果画面へ進みます。未開封の宝箱の効果は受け取りません。

どちらを選んでも、クリア時に残った経験値コインは回収されます。持ち帰り経験値は終了処理で一度だけ兵士へ反映・保存します。続行を選んだ時点では持ち帰り経験値を確定せず、その後の終了時にまとめて反映します。

## 対象範囲

専用ボスと巨大化はサバイバルだけに適用します。探索・通常防衛・攻城戦・秘境など、ほかのモードのボスや進行ルールは変更しません。大ボスの戦闘状態とプチエンディングの表示状態はその挑戦内で管理し、兵士の保存形式は追加しません。
