# 兵士の戦歴・称号・個人成長ガイド（v91）

「情報 → 兵士」または「編成 → 詳細・育成」から確認できます。

## 成長適性

| 適性 | 成長分の特徴 |
| --- | --- |
| 豪腕型 | 攻撃+10%、HP−5% |
| 頑健型 | HP・防御各+5%、攻撃−5% |
| 救護型 | 回復+10%、攻撃−5% |
| 万能型 | HP・攻撃・防御・回復各+2% |

適性は兵士ごとに固定され、転職・復活でも変わりません。今の職業に対応する能力が伸びます。既存兵士は導入時の能力を維持し、今後のレベルアップから適用します。装備・書・果実の数値を適性で直接増減しません。

主人公がLv1から再出発したときは、適性・戦歴・習得済みスキルを保持し、レベルに対応する成長差だけをリセットします。射程・攻撃速度・回避率の個人差は今回の対象外です。

## 戦歴から得る閃き

条件を達成し、戦歴の保存が完了すると習得します。既存のレベルアップ時の低確率の閃き21技はそのままです。戦歴由来の9技は確定習得で、有効にするにはLv10以上と適性が必要です。

| 技 | 習得条件（導入後の本人の実績） | 効果 |
| --- | --- | --- |
| 踏ん張り | HP30%以下から3回生還 | 敵攻撃でHP30%以下になった後4秒間、被ダメージ−10%。再使用30秒 |
| 生存への執念 | HP10%以下から3回生還 | HP30%未満のとき受ける回復+15% |
| 討ち取り上手 | 100体討伐 | 撃破後5秒間、攻撃+5%。重複加算なし、再使用10秒 |
| 歴戦の刃 | 1,000体討伐 | 確定討伐100体ごと攻撃+1%、最大+10% |
| 救護の積み重ね | 実回復量1,000 | 実回復量1千／1万／10万で回復+3%／6%／10% |
| 緊急救命 | 瀕死の味方を10回救命 | HP30%未満の味方を治療するとき追加20%回復。再使用25秒 |
| 大物狩り | ボス10体に最後の一撃 | ボスに与えるダメージ+5% |
| かばう | 近接被弾の生還点10点 | 近接職で瀕死の味方への通常攻撃30%を引き受ける。自身HP50%以上・再使用12秒 |
| 黄泉返り | 復活の書などで正式に復活 | 技を有効にして出撃する最初の戦闘で8秒間、被ダメージ−15%。次の正式な復活で再使用可 |

攻撃系は攻撃する職業、回復系は治療する職業で有効です。習得した技は転職後も保持します。既存の閃きと合わせて有効2枠、書の装備4冊は別枠です。

生還は通常防衛・修練場では1ウェーブ、攻城・秘境では1戦を勝利・クリアして生き残ることで成立します。同じ判定単位でHPを上下させても、生還回数は増えません。主人公の再出発や、戦死してからの復活を同じ戦闘での生還として数えません。

回復量は実際に戻したHPを数えます。過剰回復、全回復ボタン、戦闘外の有料治療、復活時のHP復元は対象外です。救命はHP30%未満から50%以上へ戻したときに数えます。

## 近接・遠距離耐性

敵攻撃で実際にHPが減り、そのウェーブ・戦闘を生還すると、それぞれの熟達点が増えます。1回の判定単位で増える点には上限があります。

| 熟達点 | その攻撃種別の軽減 |
| --- | --- |
| 10 | 3% |
| 50 | 6% |
| 150 | 10% |

上位段階に置き換わり、3%+6%+10%とはなりません。特殊攻撃は対象外です。耐性は恒久的な戦歴熟達で、閃き枠は使いません。「戦歴帳」に現在の耐性を表示します。

## 称号・記念報酬

- 討伐、実回復、救命、瀕死生還、復活、被弾後の生還、強敵討伐・支援から18種類の称号を得られます。
- 称号は複数所持でき、表示は1つ選べます。表示を切り替えても能力は変わりません。既存の「熟練兵・英雄」などの階級による補正とは別です。
- 過去の討伐数は称号に反映します。装備報酬と戦歴スキルは導入後の実績から獲得します。
- 記念報酬は「称号・記念報酬」の「受け取る」で入手します。倉庫が満杯なら受取待ちに残ります。
- 百人斬りの刀、千軍の武功章、救命の数珠、生還の護符、黄泉の守りの5種類を追加しました。装備枠と装備できる職業は既存ルールに従います。
- 報酬は兵士の生涯ごと・実績ごとに1回です。復活で再発行しません。記念装備は最初からロックされています。
- 称号と記念装備は戦国図鑑に記録します。次に目指す戦歴は兵士の詳細に表示します。

## 指導員への引退

既存と同じく、生存するLv100以上の非主人公が対象です。引退時に、既存能力か習得済みの閃きのどれか1つを選んで残せます。

称号・適性・討伐数・回復量・耐性熟達・黄泉返りの使用権は継承しません。「歴戦の刃」などは、受け取った兵士自身の実績を参照します。「黄泉返り」を継承しても、本人が復活していなければ発動しません。

## 保存と従来のスキル

戦歴は既存の進行保存と一緒に確定します。保存失敗時は、未確定の新スキルを戦闘効果や継承に使用しません。報酬の受取も取り消して再試行できます。別タブで保存された進行を検出した場合は、古い画面からの上書きを止めるので、その画面を再読み込みしてください。

既存の「不屈」と不死鳥の護符は維持しています。今回、同名の追加残機や新しい致命傷無効を重ねていません。俊敏・狙撃タイプの追加は次の段階で扱います。

## 死線からの不屈習得（v90）

HP一桁（最大HP100以上）で敵攻撃から生き残り、その戦闘に勝利した記録を3回保存すると、兵士詳細の「不屈を習得」で既存の通常スキルを得られます。通常スキル20枠の1つで、満枠なら習得だけして後から選択します。既に持つ不屈と重複せず、1ウェーブ・1戦に1回HP1で耐える従来効果です。追加の残機はありません。撤退・敗北・戦死は生還回数に加算しません。

## かばう（v91）

近接被弾の生還点10点で戦歴閃き「かばう」を習得します。Lv10以上の近接職で有効にすると、同じ部隊のHP30%未満の味方への通常攻撃の30%を引き受けます。自身HP50%以上・再使用12秒。部隊内でHP割合の高い候補1人だけが発動し、範囲・特殊攻撃は対象外、引き受けたダメージを再転送しません。肩代わり後はそれぞれの防御・回避・盾などで計算し、守った兵士も戦死し得ます。

実際にHPを失ってかばい、その戦闘で勝利・生還すると実績が1戦分増え、3戦で称号「仲間の盾」を得ます。称号に追加能力はありません。閃きは既存2枠の1つで、指導員から技を継承しても戦歴は継承しません。
