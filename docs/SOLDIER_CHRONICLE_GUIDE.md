# 兵士の戦歴・称号・個人成長ガイド（v95）

「情報 → 兵士」または「編成 → 詳細・育成」から確認できます。

v95から、兵士詳細の上部に「攻撃間隔：○秒／回避率：○％」を折りたたまず表示します。衛生兵は「回復間隔」です。スキル・装備・適性・保存済み戦歴・配属武将を合算した値で、戦歴だけの増加分は従来の「戦歴ボーナス」で確認できます。攻城中はその部隊の武将・氷結による間隔も反映します。秒数はゲーム内時間のため、倍速を選んでも表示値は変わりません。回避率は合計40％が上限で、回避後2秒間の再発動制限は別にあります。職業固有技の再使用待ちや騎馬鉄砲の構えは通常行動の間隔とは別です。

## 成長適性

| 適性 | 成長分の特徴 |
| --- | --- |
| 豪腕型 | 攻撃+10%、HP−5% |
| 頑健型 | HP・防御各+5%、攻撃−5% |
| 救護型 | 回復+10%、攻撃−5% |
| 万能型 | HP・攻撃・防御・回復各+2% |
| 俊敏型 | 成長に応じ行動間隔最大−3%、回避最大＋2ポイント |
| 狙撃型 | 成長に応じ遠距離攻撃職の基本射程最大＋5% |

適性は兵士ごとに固定され、転職・復活でも変わりません。今の職業に対応する能力が伸びます。既存兵士は導入時の能力を維持し、今後のレベルアップから適用します。装備・書・果実の数値を適性で直接増減しません。

主人公がLv1から再出発したときは、適性・戦歴・習得済みスキルを保持し、レベルに対応する成長差だけをリセットします。俊敏・狙撃の二次成長も再出発でゼロに戻ります。

## 戦歴から得る閃き

条件を達成し、戦歴の保存が完了すると習得します。既存のレベルアップ時の低確率の閃き21技はそのままです。戦歴由来の9技は確定習得で、有効にするにはLv10以上と適性が必要です。

| 技 | 習得条件（導入後の本人の実績） | 効果 |
| --- | --- | --- |
| 踏ん張り | HP30%以下から3回生還 | 敵攻撃でHP30%以下になった後4秒間、被ダメージ−10%。再使用30秒 |
| 生存への執念 | HP10%以下から3回生還 | HP30%未満のとき受ける回復+15% |
| 討ち取り上手 | 100体討伐 | 撃破後5秒間、攻撃+5%。重複加算なし、再使用10秒 |
| 歴戦の刃 | 1,000体討伐 | 確定討伐100体ごと攻撃+1%、最大+10% |
| 救護の積み重ね | 実回復量1,000 | 実回復量1千／1万／10万で回復+3%／6%／10% |
| 緊急救命 | 瀕死の味方を10回救命 | HP30%未満の味方を治療するとき追加20%回復。再使用25秒 |
| 大物狩り | ボス10体に最後の一撃 | ボスに与えるダメージ+5% |
| かばう | 近接被弾の生還点10点 | 近接職で瀕死の味方への通常攻撃30%を引き受ける。自身HP50%以上・再使用12秒 |
| 黄泉返り | 復活の書などで正式に復活 | 技を有効にして出撃する最初の戦闘で8秒間、被ダメージ−15%。次の正式な復活で再使用可 |

攻撃系は攻撃する職業、回復系は治療する職業で有効です。習得した技は転職後も保持します。既存の閃きと合わせて有効2枠、書の装備4冊は別枠です。

生還は通常防衛・修練場では1ウェーブ、攻城・秘境では1戦を勝利・クリアして生き残ることで成立します。同じ判定単位でHPを上下させても、生還回数は増えません。主人公の再出発や、戦死してからの復活を同じ戦闘での生還として数えません。

回復量は実際に戻したHPを数えます。過剰回復、全回復ボタン、戦闘外の有料治療、復活時のHP復元は対象外です。救命はHP30%未満から50%以上へ戻したときに数えます。

## 近接・遠距離耐性

敵攻撃で実際にHPが減り、そのウェーブ・戦闘を生還すると、それぞれの熟達点が増えます。1回の判定単位で増える点には上限があります。

| 熟達点 | その攻撃種別の軽減 |
| --- | --- |
| 10 | 3% |
| 50 | 6% |
| 150 | 10% |

上位段階に置き換わり、3%+6%+10%とはなりません。特殊攻撃は対象外です。耐性は恒久的な戦歴熟達で、閃き枠は使いません。「戦歴帳」に現在の耐性を表示します。

## 称号・記念報酬

- 討伐、実回復、救命、瀕死生還、復活、被弾後の生還、強敵討伐・支援から18種類の称号を得られます。
- 称号は複数所持でき、表示は1つ選べます。表示を切り替えても能力は変わりません。既存の「熟練兵・英雄」などの階級による補正とは別です。
- 過去の討伐数は称号に反映します。装備報酬と戦歴スキルは導入後の実績から獲得します。
- 記念報酬は「称号・記念報酬」の「受け取る」で入手します。倉庫が満杯なら受取待ちに残ります。
- 百人斬りの刀、千軍の武功章、救命の数珠、生還の護符、黄泉の守りの5種類を追加しました。装備枠と装備できる職業は既存ルールに従います。
- 報酬は兵士の生涯ごと・実績ごとに1回です。復活で再発行しません。記念装備は最初からロックされています。
- 称号と記念装備は戦国図鑑に記録します。次に目指す戦歴は兵士の詳細に表示します。

## 指導員への引退

既存と同じく、生存するLv100以上の非主人公が対象です。引退時に、既存能力か習得済みの閃きのどれか1つを選んで残せます。

称号・適性・討伐数・回復量・耐性熟達・黄泉返りの使用権は継承しません。「歴戦の刃」などは、受け取った兵士自身の実績を参照します。「黄泉返り」を継承しても、本人が復活していなければ発動しません。

## 保存と従来のスキル

戦歴は既存の進行保存と一緒に確定します。保存失敗時は、未確定の新スキルを戦闘効果や継承に使用しません。報酬の受取も取り消して再試行できます。別タブで保存された進行を検出した場合は、古い画面からの上書きを止めるので、その画面を再読み込みしてください。

既存の「不屈」と不死鳥の護符は維持しています。今回、同名の追加残機や新しい致命傷無効を重ねていません。追加の不屈とは異なる致命傷無効はありません。

## 死線からの不屈習得（v90）

HP一桁（最大HP100以上）で敵攻撃から生き残り、その戦闘に勝利した記録を3回保存すると、兵士詳細の「不屈を習得」で既存の通常スキルを得られます。通常スキル20枠の1つで、満枠なら習得だけして後から選択します。既に持つ不屈と重複せず、1ウェーブ・1戦に1回HP1で耐える従来効果です。追加の残機はありません。撤退・敗北・戦死は生還回数に加算しません。

## かばう（v91）

近接被弾の生還点10点で戦歴閃き「かばう」を習得します。Lv10以上の近接職で有効にすると、同じ部隊のHP30%未満の味方への通常攻撃の30%を引き受けます。自身HP50%以上・再使用12秒。部隊内でHP割合の高い候補1人だけが発動し、範囲・特殊攻撃は対象外、引き受けたダメージを再転送しません。肩代わり後はそれぞれの防御・回避・盾などで計算し、守った兵士も戦死し得ます。

実際にHPを失ってかばい、その戦闘で勝利・生還すると実績が1戦分増え、3戦で称号「仲間の盾」を得ます。称号に追加能力はありません。閃きは既存2枠の1つで、指導員から技を継承しても戦歴は継承しません。

## 俊敏・狙撃の二次成長（v92）

v92以降に新しく雇う兵士は6タイプから固定されます。既存兵士は4タイプを維持し、適性が欠けている古い保存でも4タイプから移行します。転職・復活で再抽選しません。

俊敏型は攻撃・回復の間隔を最大3%短縮し、回避を最大2ポイント追加します。合計回避の上限40%と発動後2秒の制限を維持します。狙撃型は遠距離攻撃職で基本射程を最大5%延長し、装備・書・果実の追加射程を増幅しません。治療・近接職では射程補正なしです。

補正はLv1でゼロ。レベル成長分を累積し、`成長量 ÷（成長量＋20）` で上限へ緩やかに近づきます。多段レベルアップを一度ずつ数え、同じレベルへの再到達・転職で増殖しません。

## 記念装備の戦歴成長（v93）

装備者本人の保存済み戦歴で3段階に成長します。Ⅰは従来の元性能、Ⅱ・Ⅲで追加効果が解放されます。装備品自体に実績は保存しないため、別の兵士へ渡すと、その兵士の実績で段階が決まります。

| 装備 | Ⅰ：元の性能 | Ⅱ：必要実績と性能 | Ⅲ：必要実績と性能 |
| --- | --- | --- | --- |
| 百人斬りの刀 | 攻撃+12% | 導入後500討伐：+14% | 1,000討伐：+16% |
| 千軍の武功章 | 攻撃・防御+6% | 2,500討伐：各+7% | 5,000討伐：各+8% |
| 救命の数珠 | 回復量+10% | 実回復5万：+12% | 10万：+15% |
| 生還の護符 | 最大HP+5% | HP一桁で勝利・生還3回：+7% | 10回：+10% |
| 黄泉の守り | 被ダメージ−3% | 正式な復活3回：−4% | 10回：−5% |

倉庫の装備説明、兵士詳細の「記念装備の戦歴成長」、図鑑に条件を表示します。未保存の実績では追加効果を使いません。段階を上げても現在HPは回復しません。元の装備枠・職業条件・ロック・売却ルールは維持します。過去討伐の遡及分は段階条件に含みません。

## 戦歴ボーナス（v94）

「詳細・育成 → 📈 戦歴ボーナス」で現在の合計と項目別の内訳を確認できます。全職業に適用し、閃き2枠・通常スキル20枠・書4冊を消費しません。

| 保存済みの記録 | 区切りごとの補正 |
| --- | --- |
| 生存W 1W | 最大HP＋1 |
| 累計討伐100体（ボスを含む） | 攻撃＋1 |
| ボス討伐10体 | 攻撃＋1 |
| ボス討伐支援100回 | 攻撃・回復の行動速度＋0.1%、最大＋10% |
| 近接被弾1,000回 | 防御＋1 |
| 遠距離被弾2,000回 | 防御＋1 |
| HP30%以下で勝利・生還100回 | 防御＋1 |
| HP10%以下で勝利・生還50回 | 防御＋1 |
| HP一桁で勝利・生還100回 | 回避率＋0.1ポイント、最大＋5ポイント |

端数は切り捨て、累計の区切りごとに増えます。討伐・生存Wは従来からの保存記録、それ以外は戦歴機能導入後の記録を使います。ボスを倒せば累計討伐とボス討伐の両方に数えます。瀕死生還は各条件を同時に満たせますが、各条件は同じ戦闘につき1回まで。敗北・戦闘全体の撤退・戦死は瀕死生還へ加算しません。

HP・攻撃・防御は、武将・職業・装備・書・果実・戦歴閃きなどの計算後に固定値として加算します。攻城・秘境の武将や鼓舞でもこの固定値を増幅しません。支援速度＋1%なら行動間隔を1.01で割ります（1秒短縮ではありません）。回避の合計上限40%と発動後2秒の制限を維持。戦歴による射程の追加はありません。

記録を能力値へ加算保存せず、保存済みの記録から計算するので、再読込・転職・主人公のLv1再出発で二重加算しません。最大HPが増えただけでは現在HPを回復しません。従来のウェーブ終了時の回復や正式な復活は別です。記録の保存失敗時は未確定分の補正を使わず、確定ログが残っていれば転記失敗後も復旧します。

v94以降の戦死の控えには生存Wも残し、復活の書で引き継ぎます。以前の英霊名鑑には生存Wが保存されていなかったため、既に戦死済みでその値が欠けている兵士のW数は復元できません。
