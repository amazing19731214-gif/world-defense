# 自動奥義（v124）

習得済みの奥義は、対応する職業の兵士が戦場にいると自動発動します。通常TD・修練場（試作OFF/ON）・攻城戦・秘境討伐・探索・サバイバル・三方の関で同じ処理を使います。

- 最初の抽選は戦闘参加からゲーム内60秒後。抽選確率は30％です。成功・失敗のどちらも、次の抽選まで60秒待ちます。対象がいない場合は準備完了のまま待ち、範囲内の敵が現れてから抽選します。
- 平均発動間隔は戦闘中の約3分20秒です。倍速ではゲーム内時間に合わせて進みます。停止・メニュー・タブ非表示・レベルアップ選択・宝箱中は進みません。待機候補や未出撃・戦死した兵士の時計も進みません。
- WAVE・モードを変えても兵士本人の待ち時間を引き継ぎます。現在の待ち時間は定期的に保存し、ページ終了時にも保存を試みます。再読み込みでは保存済みの待ち時間を復元します。未保存の進捗が失われる場合は、次の抽選がその分遅くなります。
- 抽選番号と次の60秒待ちは、ダメージを与える前に保存します。保存できなければ発動を止めて再試行し、抽選結果をリロードで引き直せないようにします。別タブが奥義データを書き換えた場合は上書きしません。
- 兵士1人につき有効な奥義は1種類。「情報 → 兵士 → ⚔ 奥義」から切替・解除できます。自分で閃いた奥義は最初の1種類が自動で有効になります。全軍で1人の制限はありません。
- 奥義書は消費しませんが、1冊を同時に継承できるのは1人です。別の兵士へ渡すときは元の継承を解除します。書の複製は行いません。書による継承と本人が閃いた奥義の両方から、1種類を選びます。
- 複数人が同時に準備完了になった場合は、演出を少しずらして発動します。連続斬撃の途中で発動者が倒れたり戦闘が切り替わった場合、残りの攻撃は終了します。

## 剣聖の3種類

以下の3種類は剣聖用です。転職で職業条件を外れると使えず、剣聖へ戻ると保存した設定を利用できます。技の元の威力・範囲は変更しません。

| 奥義 | 効果 |
| --- | --- |
| 八方天翔斬 | 八方向の巨大な斬撃波 |
| 無明一閃 | 強敵1体を優先する強烈な一撃 |
| 天剣乱舞 | 周囲へ6回の連続斬撃 |

防衛の敵へのダメージ、攻城の守備兵・塔・城、秘境のボス、探索・サバイバルの敵には、それぞれ既存のダメージ処理を通します。装甲・ボスの防御、討伐・経験値・報酬の処理を共通化のために省略しません。サバイバル内での敵撃破による本来の兵士EXPは、現行の持ち帰り経験値（参加中の共通EXPと同量）のルールに従います。宝箱の「奥義の秘伝書」は、その挑戦の主人公の奥義威力を上げる既存の効果を維持します。

## 剣聖の入手・保存の引き継ぎ

剣聖の入手方法は変更しません。剣聖・Lv150以上・剣聖熟練10以上・強敵への最後の一撃10回以上を満たす兵士が、修練場の「新しい戦い（試作）」で強敵撃破・挑戦クリア時に閃く抽選を受けます。初期2％、連続不発10回ごとに1ポイント加算、最大10％です。50回目の対象抽選では確定で習得します。指導員引退で奥義書を1冊残す仕組みも維持します。

保存先は従来の `worldDefense.ougi.v1` のままです。`auto` に兵士の生涯IDごとの選択と時計を追加し、既存の知識・書・閃き抽選履歴を維持します。旧継承者の選択も利用できます。旧来の `heir`・`run` は読込互換用として残し、新しい自動発動回数の制限には使いません。英霊名鑑に残る本人の知識・自動設定・時計は、復活時も同じ生涯IDで対応します。戦死した兵士の奥義書による継承は解除され、書は残ります。

## 検証

- `tools/test-auto-ougi.mjs`：全モード・3技の実効果、確率境界、待ち時間、保存障害・旧セーブ・複数兵・職業条件・画面幅。
- `tools/test-legend-ougi.mjs`：TD・修練場・攻城・秘境の実際のゲーム更新からの発動と停止。
- `tools/test-trial-ougi.mjs`：探索・サバイバル・三方の関の実際の更新と、主人公以外の仲間の発動。
- `tools/test-ougi-books.mjs`：入手条件、奥義書、引退、保存失敗、復活、倉庫上限。

iPhone Safari実機での確認は別途必要です。自動発動する人数が増えるほど軍全体の攻撃機会も増えるため、長時間の難易度バランスは人間のプレイでも確認してください。


## ほかの最上級職の奥義（v123）

通常TD・修練場（試作OFF/ON）・攻城戦・秘境・探索・サバイバル・三方の関で使える奥義を、各職1種類ずつ追加します。各兵士は1種類を有効にし、60秒ごと30%で自動発動します。回復・防御奥義は味方が負傷しているときだけ抽選し、それまでは準備完了のまま待ちます。医王の対象は生存兵だけで、蘇生・城ハート回復・塔の回復は行いません。

| 職業 | 奥義 | 効果 |
|---|---|---|
| 忍頭 | 影縫い・百鬼夜行 | 周囲220・最大5体へ攻撃力200%。通常敵は3秒停止。ボス・中ボスは停止せず、8秒攻撃15%低下 |
| 槍将 | 不動・千本槍陣 | 前方180・幅45・最大6体へ攻撃力300%。自身へ最大HP20%の盾・8秒35%軽減。TDでは部隊の足止め上限+1（人数上限以内） |
| 弓聖 | 天弓・流星雨 | 現在の射程内・最大6体へ各3発、1発攻撃力180%。1体に集中しても3発まで |
| 銃将 | 轟砲・国崩し | 射程300・着弾点から100・最大6体へ攻撃力500%。装甲を追加35%無視（既存分と合計80%まで）、構造物へ威力1.3倍 |
| 鉄騎将 | 鉄壁・守護騎陣 | 同部隊の味方最大3人に最大HP25%の盾、8秒ダメージ30%肩代わり。自身に最大HP15%の盾・20%軽減。戦場試練の出撃者は同じ隊として扱う |
| 医王 | 命脈・再生の聖域 | 周囲240の負傷兵最大3人へ通常回復量200%の回復と最大HP10%の盾。8秒間、毎秒通常回復量20%の継続回復 |

一時効果はWAVE・モード・戦場試練の面をまたぎません。盾は同系統の量を加算して増殖させず、肩代わりは連鎖しません。発動者が戦死・離脱すると、肩代わりや継続回復は終了します。既存の防御・装甲・ボス耐性・討伐・経験値の処理を通します。

### 習得条件

共通：現在職が対応する最上級職、Lv150以上、現在職の熟練度10/10、未習得の対応奥義があること。

- 忍頭：自身が妨害した敵の討伐貢献10体。
- 槍将：足止めに貢献して勝利生還10戦／WAVE。
- 弓聖・銃将：強敵討伐・支援10回。既存の保存済みボス討伐＋支援も使います。新しい集計では中ボスも含みます。
- 鉄騎将：かばって勝利生還、または自身が与えた味方の盾が実際にダメージを吸収して勝利生還10戦／WAVE。既存のかばう勝利生還も使います。
- 医王：本人の累計実回復50,000、救命生還10回。救命生還はHP30%以下の味方に正の実回復を与え、回復者と対象の双方が勝利生還したとき。同じ対象は1WAVE／戦闘につき1回。空振り・自己回復・戦死者は救命として数えません。実回復量には既存の保存済み回復量も使います。

条件を満たし、本人が攻撃・回復・防御に貢献して生還した勝利WAVE／戦闘で1回抽選します。通常TDと修練場はWAVEクリア、攻城・秘境は勝利、サバイバルは面クリア、三方の関は勝利、探索は正常帰還が対象です。敗北・時間切れ・単なる待機は抽選しません。新しい救命生還・妨害・足止め・盾の生還記録は導入後から集計し、過去の履歴を推測して付け足しません。

初期2%、連続不発10回ごとに+1ポイント、最大10%。50回目の対象抽選では確定で習得します。戦闘中の回復ごとには抽選しません。保存済みの勝利と実績を確認してから抽選し、結果・失敗数・その勝利の抽選済み印を既存の`worldDefense.ougi.v1`へ一緒に保存します。再読み込み・同じ結果の再表示では引き直しません。奥義保存失敗は同じ番号で再試行します。

試練では写しの戦歴を本物から分離し、成功した区間の生存参加者について、奥義に必要な回復・新実績だけを本物の兵士保存へ一度だけ取り込みます。経験値の持ち帰り処理は既存のままです。

### 奥義書と表示

自分で閃いた兵士は、指導員引退時に対応する奥義書を1冊残せます。書は消費せず同時に1人まで継承でき、対応する職業で使用できます。書を継承しただけの兵士を引退させても、その書を複製しません。既存の剣聖の知識・書・自動設定・待ち時間と、4冊の装備書・2枠の閃き装備は維持します。

兵士の詳細・育成の「⚔ 奥義」から、職業別の習得条件・進捗・奥義書・自動発動を確認できます。

試練の攻撃倍率は奥義へ1回だけ適用します。発動側と命中側で二重に掛かっていた既存の奥義についても、倍率2倍で威力4倍になる重複を修正しています。

追加検証：`tools/test-ultimate-ougi.mjs`（6職・全モード・習得・奥義書）、`tools/test-ultimate-ougi-support.mjs`（実際の肩代わり・終了条件・継続回復・試練の実績確定・画面・攻撃倍率の重複防止）。


## 習得率と表示の改善（v124）

初期習得率を2%、連続不発10回ごと+1ポイント、通常の上限10%に変更しました。連続49回不発の次（50回目）は乱数によらず確定で習得します。従来の連続不発回数を保持し、49回以上たまっている兵士も、次の条件を満たす対象抽選で確定になります。画面を開くだけで習得させる処理はありません。習得すると連続不発回数は0へ戻ります。1人で複数の奥義を覚える場合や転職した場合も、従来どおり本人の連続不発回数を使います。

奥義画面に必要条件と本人の現在Lv・現在職熟練度を分けて表示し、実際の習得抽選回数、連続不発回数、次回の習得率、確定までの回数を表示します。討伐・支援139回という記録が習得抽選139回を意味するわけではありません。戦闘中の発動率30%とは独立しています。剣聖の習得場所（修練場・新しい戦いの試作）は変更せず、画面内でも明記します。
