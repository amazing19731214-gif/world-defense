# 自動奥義（v117）

習得済みの奥義は、対応する職業の兵士が戦場にいると自動発動します。通常TD・修練場（試作OFF/ON）・攻城戦・秘境討伐・探索・サバイバル・三方の関で同じ処理を使います。

- 最初の抽選は戦闘参加からゲーム内60秒後。抽選確率は30％です。成功・失敗のどちらも、次の抽選まで60秒待ちます。対象がいない場合は準備完了のまま待ち、範囲内の敵が現れてから抽選します。
- 平均発動間隔は戦闘中の約3分20秒です。倍速ではゲーム内時間に合わせて進みます。停止・メニュー・タブ非表示・レベルアップ選択・宝箱中は進みません。待機候補や未出撃・戦死した兵士の時計も進みません。
- WAVE・モードを変えても兵士本人の待ち時間を引き継ぎます。現在の待ち時間は定期的に保存し、ページ終了時にも保存を試みます。再読み込みでは保存済みの待ち時間を復元します。未保存の進捗が失われる場合は、次の抽選がその分遅くなります。
- 抽選番号と次の60秒待ちは、ダメージを与える前に保存します。保存できなければ発動を止めて再試行し、抽選結果をリロードで引き直せないようにします。別タブが奥義データを書き換えた場合は上書きしません。
- 兵士1人につき有効な奥義は1種類。「情報 → 兵士 → ⚔ 奥義」から切替・解除できます。自分で閃いた奥義は最初の1種類が自動で有効になります。全軍で1人の制限はありません。
- 奥義書は消費しませんが、1冊を同時に継承できるのは1人です。別の兵士へ渡すときは元の継承を解除します。書の複製は行いません。書による継承と本人が閃いた奥義の両方から、1種類を選びます。
- 複数人が同時に準備完了になった場合は、演出を少しずらして発動します。連続斬撃の途中で発動者が倒れたり戦闘が切り替わった場合、残りの攻撃は終了します。

## 現在の3種類

すべて剣聖用です。転職で職業条件を外れると使えず、剣聖へ戻ると保存した設定を利用できます。技の元の威力・範囲は変更しません。

| 奥義 | 効果 |
| --- | --- |
| 八方天翔斬 | 八方向の巨大な斬撃波 |
| 無明一閃 | 強敵1体を優先する強烈な一撃 |
| 天剣乱舞 | 周囲へ6回の連続斬撃 |

防衛の敵へのダメージ、攻城の守備兵・塔・城、秘境のボス、探索・サバイバルの敵には、それぞれ既存のダメージ処理を通します。装甲・ボスの防御、討伐・経験値・報酬の処理を共通化のために省略しません。サバイバル内での敵撃破による本来の兵士EXPは、v116の持ち帰り経験値のルールに従います。宝箱の「奥義の秘伝書」は、その挑戦の主人公の奥義威力を上げる既存の効果を維持します。

## 入手・保存の引き継ぎ

入手方法は変更しません。剣聖・Lv150以上・剣聖熟練10以上・強敵への最後の一撃10回以上を満たす兵士が、修練場の「新しい戦い（試作）」で強敵撃破・挑戦クリア時に閃く抽選を受けます。最初は0.1％、連続失敗10回ごとに0.1ポイント加算、最大2％です。指導員引退で奥義書を1冊残す仕組みも維持します。

保存先は従来の `worldDefense.ougi.v1` のままです。`auto` に兵士の生涯IDごとの選択と時計を追加し、既存の知識・書・閃き抽選履歴を維持します。旧継承者の選択も利用できます。旧来の `heir`・`run` は読込互換用として残し、新しい自動発動回数の制限には使いません。英霊名鑑に残る本人の知識・自動設定・時計は、復活時も同じ生涯IDで対応します。戦死した兵士の奥義書による継承は解除され、書は残ります。

## 検証

- `tools/test-auto-ougi.mjs`：全モード・3技の実効果、確率境界、待ち時間、保存障害・旧セーブ・複数兵・職業条件・画面幅。
- `tools/test-legend-ougi.mjs`：TD・修練場・攻城・秘境の実際のゲーム更新からの発動と停止。
- `tools/test-trial-ougi.mjs`：探索・サバイバル・三方の関の実際の更新と、主人公以外の仲間の発動。
- `tools/test-ougi-books.mjs`：入手条件、奥義書、引退、保存失敗、復活、倉庫上限。

iPhone Safari実機での確認は別途必要です。自動発動する人数が増えるほど軍全体の攻撃機会も増えるため、長時間の難易度バランスは人間のプレイでも確認してください。
