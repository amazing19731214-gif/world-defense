# 伝説の奥義・奥義書・奥義継承者（v106.2試作・v106.3で確率・挑戦ID・倉庫の整理）

PR #128（伝説の奥義 Phase 1）の上に作った試作です。**正式な仕様ではありません。** 奥義を使えるのも閃くのも、修練場の「🧪 新しい戦い（試作）」の中だけです。今回の対象は剣聖だけです。

## 全体の流れ

1. 剣聖を育てる（Lv150・剣聖の熟練度10・強敵への最後の一撃10回）。
2. 修練場（試作）で強敵を倒したときや、クリアしたときに、ごくまれに伝説の奥義を閃く。
3. 剣聖の兵士の画面の「⚔ 奥義」から、その奥義で奥義継承者になる（全軍で1人）。
4. 修練場（試作）で、奥義継承者がボタンで奥義を使う（1回の挑戦で全軍1回）。
5. 奥義を閃いた剣聖が指導員として引退すると、奥義書を1冊残す。
6. 次の世代の剣聖が奥義書を継承して、奥義継承者になる。

## 伝説の奥義（剣聖）

| 奥義 | 内容 |
| --- | --- |
| 八方天翔斬 | まわりへ巨大な八方向の斬撃波（画面の端まで） |
| 無明一閃 | 強敵1体（大将 → 中ボス → 体力の多い敵）へ強烈な一閃 |
| 天剣乱舞 | 広い範囲へ6回の連続斬撃 |

`LEGEND_OUGI` の `job` でほかの最上級職の固有奥義も足せる形です（今回は作っていません）。

## 奥義の閃き

- **条件**：今の職業が剣聖・Lv150以上・剣聖の熟練度10・戦歴「強敵への最後の一撃」10回以上。
- **抽選する場面**：修練場（試作）で、
  - 強敵（中ボス・大将）に最後の一撃を入れたとき（その兵士だけ）；
  - 修練場をクリアしたとき（戦った剣聖それぞれ）。
  - 通常攻撃や雑魚の撃破では抽選しません。
- **確率**（v106.3）：初めは 0.1%。続けて外れた回数10回ごとに +0.1ポイント上がり、最大2%です（`OUGI_RULES`）。

  | 続けて外れた回数 | 次の確率 |
  | --- | --- |
  | 0〜9回 | 0.1% |
  | 10〜19回 | 0.2% |
  | 20〜29回 | 0.3% |
  | 50〜59回 | 0.6% |
  | 100〜109回 | 1.1% |
  | 190回以上 | 2.0% |

  - 外れた回数は兵士ごと（戦歴の一生ごと）に保存します。閃いたら0に戻します。
  - 3つすべて覚えた剣聖は、もう抽選しません。
  - 目安：最初の奥義までに平均 約122回の抽選。100回で約42%、190回で約85%、300回で約98%。修練場の100ウェーブ1回では、抽選は最大21回（強敵20体・クリア1回）。
- **まだ知らない奥義**から1つ選ばれます。
- **記録**：閃きの2枠とは別に、伝説の奥義として記録します。
- **乱数**：結果は、兵士の閃きの種（既存の閃きと同じ）と、その兵士が引いた回数で決まります。回数・外れた回数は結果と一緒に保存するので、再読み込みしても同じ回を引き直せません。
- **閃いたとき**：技名の帯「閃き！ 奥義・○○」（兵士の名前つき）、兵士の所の光、イベントウィンドウ、兵士の記録に出します。

## 奥義書

- 奥義を閃いた剣聖が「指導員として引退」すると、伝承の秘伝書とは**別に**1冊残します。
  - 複数の奥義を知っていれば、引退の画面で1つ選びます。
  - 伝承の秘伝書の選び方・200冊の倉庫・1人4冊の装備枠は変えていません。奥義書はどれにも入りません。
- **記録すること**：奥義のID、伝承者の名前、引退時の職業・Lv、作成日時。
- **扱い**：消費しません。倉庫は500冊までです。
- **倉庫が満杯のとき**：奥義を閃いた剣聖の引退の画面に、引退の前に「倉庫がいっぱい」と出します。引退させるボタンは出さず、整理の画面へのボタンを出します。
- **処分**：奥義の画面で「🗑 処分…」→「処分する」の2段階で確かめてから処分します。
  - 継承中の奥義書は、継承をやめるまで処分できません。
  - 処分しても、兵士の能力・伝承の秘伝書・兵士の保存データは変わりません。
- **有効な数**：有効にできる奥義書は全軍で1冊です（奥義継承者が継承している書）。

## 奥義継承者

- 全軍で1人です。剣聖だけがなれます（剣聖への転職は何人でもできます）。
- **なれる人**：
  - 自分で閃いた剣聖は、奥義書なしで継承者になれます。
  - 奥義書を継承した剣聖もなれます。
- **変更**：別の兵士を継承者にすると、前の継承者は外れます。前の継承者の奥義書は倉庫に戻ります。
- **変えられる時**：戦闘の前（ウェーブの合間）だけです。修練場の挑戦中・攻城戦中・ウェーブ中は変えられません。
- **表示**：兵士名簿で「⚔ 奥義継承者」の印を付けます。

## 1回の挑戦で1回（挑戦ID・v106.3）

- 修練場を始める操作のたびに、新しい挑戦IDを発行します。新しい挑戦では、奥義はまた1回使えます。
- 奥義を使うと、挑戦IDといっしょに使用記録を保存します（保存できなければ奥義を使いません）。同じ挑戦IDでは2回使えません。
- 挑戦が終わると（クリア・撤退・敗北）、その挑戦の使用記録を確定します。
- 再読み込みだけでは新しい挑戦になりません。
  - 今の修練場は、再読み込みすると戦闘を戻せず、挑戦は終わります。
  - 次に始める挑戦は新しい挑戦IDなので、使用済みを持ち越しません。
- **将来の途中再開**：同じ挑戦IDで再開すれば、保存した使用記録から使用済みを戻せます（`ougiRunStart(runId)`）。
- 戦死・復活しても使用回数は戻りません。
- v106.2 の「挑戦IDのない使用記録」は、読み込むときに捨てます。

## 戦死・復活の書・引退

| 出来事 | 奥義継承者 | 奥義書 | 奥義の知識 |
| --- | --- | --- | --- |
| 継承者が戦死 | 指定を外す | 倉庫に残る | 英霊名鑑に載る兵士は残す（復活用）。載らない兵士は失う |
| 復活の書で戻る | 自動では戻らない | ― | 戻る（戦歴の一生 `life` で結び付け） |
| 引退 | 指定を外す | 選んだ奥義の書を1冊残す | 奥義書に移る |
| 英霊名鑑から外れた | ― | ― | 次に開いたときに消す |

## 保存

- **専用の保存キー**：`worldDefense.ougi.v1`。中身は次のとおりです。
  - `books`：奥義書
  - `known`：奥義の知識（兵士の一生ごと）
  - `rolls`：閃きを引いた回数
  - `heir`：奥義継承者
  - `fails`：続けて外れた回数（兵士の一生ごと）
  - `run`：挑戦IDと、その挑戦で使ったか
- **変えていないもの**：兵士・武将（伝承の秘伝書）の保存データと、書き込みの先行ログ（`worldDefense.bookTransaction.v1`）。
- **引退の順序**：
  1. 「引退の途中」の印を付けた奥義書を先に保存します。
  2. いつもの引退（兵士の保存）をします。
  3. 成功したら印を消して確定します。失敗したら奥義書を消します。
  4. 途中でページを閉じた場合は、次に開いたとき兵士の保存データを見て決めます。兵士が残っていれば奥義書を消し、いなければ確定します。
- **旧版に戻した場合**：
  - 旧版はこのキーを読み書きしないので、奥義書・継承者は消えません（v105.5 で遊んで戻る試験で確認）。
  - 旧版で遊んでいる間の戦死・引退は奥義の処理を通りません。次にこの版で開いたとき、兵士の保存データと突き合わせて直します。
    - いなくなった継承者の指定は外します。
    - 英霊名鑑にもいない兵士の知識は消します。
  - 旧版で引退した剣聖の奥義は、奥義書になりません（旧版は奥義を知らないため。あとから作ることもしません）。
