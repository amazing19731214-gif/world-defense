# 新ドット絵（v105試作）

設定（メニュー →「🎨 絵：従来版／新ドット絵」）で切り替える、試験的なグラフィックです。**初期設定は従来版**で、選んだプレイヤーだけ新ドット絵になります。従来のグラフィックはそのまま残しています。

## 新ドット絵で描くもの

| 対象 | 内容 |
| --- | --- |
| 兵士（基本職6種） | 足軽・槍兵・弓兵・鉄砲兵・衛生兵・騎兵。味方は藍、待機2・歩き2・攻撃1のコマ。武器は改良版（大きくデフォルメ） |
| 敵兵 | 足軽・槍兵・弓兵・騎兵（赤） |
| 塔4種 | 弓・大砲・鉄砲・水攻め。味方は藍の旗、攻城戦の敵の塔は赤の旗。強化Lvで少し大きくなるのは従来と同じ割合 |
| 城 | 防衛戦は自分の城（最初の7か国を統一すると強化した城）、攻城戦は敵の城（赤い旗） |
| 背景 | ゲームと同じ道の形の地面、木（広葉樹・松・桜・竹・茂み）・岩・灯籠・柵 |

## 従来の絵のままのもの

- 上級職・最上級職の兵士（新しい素材がない）
- 大将・特別な敵・裏ボス・討伐戦のボス
- 武将の顔・必殺技の演出・弾・エフェクト・印（主人公の冠・ネームドの星など）

## 変えていないもの

- 戦闘の処理（兵士・敵の位置、当たり判定、塔の射程、ゲームバランス）。試験で、同じ乱数で動かした戦闘の結果が従来版と同じことを確かめている。
- 保存データ。設定は表示の記録（`worldDefense.ui.v1` の `gfx`）だけに保存し、兵士・武将・領土などの保存データは変えない。以前の記録（`gfx` がない）は従来版として読む。

## 素材

- `tools/pixel/make_pixel_atlas.py` で、`tools/proto`（第2試作・武器の改良版）の絵を1枚の画像にまとめる。
  - `assets/pixel/atlas.png`（85コマ）・`atlas.json`（コマの位置と足元の基準点）・`ground.png`（地面 480×300）
- `node tools/build.mjs` で `index.html` に埋め込む（合計 約63KB）。
- 動作確認：`?gfx=pixel` で一時的に新ドット絵、`?gfx=classic` で従来版（保存はしない）。
- 試験：`node tools/test-pixel-art.mjs`
