# 新しい戦い（v106試作）

修練場の画面にある「🧪 新しい戦い（試作）」をオンにして始めた修練場だけで、新しい敵と技を試せます。**通常の防衛戦・攻城戦・全国制覇・試作なしの修練場は今までと同じ**です（試験で、同じ乱数で動かした戦闘の結果が v105.5 と同じことを確かめています）。

- 選んだかどうかは表示の記録（`worldDefense.ui.v1` の `combatProto`）だけに保存する。兵士・武将・領土などの保存データは変えない。
- 動作確認用：`?proto=combat` で一時的に試作を選ぶ（修練場を始めたときだけ有効）。

## 新しい敵

| 敵 | 動き |
| --- | --- |
| 鉄砲足軽（札「鉄」） | 部隊・塔が射程（150）に入ると止まって撃つ。3.5秒撃つと 1.2秒前へ出る（射程の外で止まり続けない）。体力は低め |
| 盾兵（札「盾」） | 硬く遅い。前に大きな木の盾。近く（80）にいる後衛が受けるダメージを ×0.4 にする |
| 連携部隊 | 盾兵1体が前、鉄砲足軽2体が後ろ（間隔 34）。後衛は盾兵を追い越さず、盾兵が倒れると前へ出る |

- 6体ごとに連携部隊（3体で3体分）、そのあとにひとりの鉄砲足軽が出る。中ボス・大将はそのまま。
- 戦い方の変化：盾の後ろの鉄砲足軽には普通の攻撃が通りにくい。**盾を抜ける貫通弾・八方斬撃**で後衛ごと倒すか、先に盾兵を倒す。

## 新しい技（兵士）

| 技 | 使う兵種 | 当たり方 | 奥義 |
| --- | --- | --- | --- |
| 三方撃ち | 弓兵など（射程が長く鉄砲以外） | 前方3方向へ1体ずつ | 奥義・千本桜（9方向・3体ずつ・遠くまで） |
| 貫通弾 | 鉄砲兵 | 1本の直線で6体まで貫く。盾を抜ける | 奥義・雷轟貫き（画面の端まで・全部貫く） |
| 八方斬撃 | 足軽・槍兵・騎兵（近接） | 8方向に斬撃波（各3体まで）。盾を抜ける | 奥義・八方天翔斬（画面いっぱいの斬撃波） |

- 通常の攻撃3回ごとに技。攻撃と撃破でゲージがたまり、満タンで奥義（奥義どうしは 2.5秒空ける）。
- 衛生兵は使わない。今ある技（職業スキル・閃き・武将の必殺技）の ID・発動条件・能力値は変えていない。

## 演出

| | 通常の技 | 奥義 |
| --- | --- | --- |
| 矢・弾 | 細い光の軌跡 | 太い軌跡 |
| 斬撃 | 8本の刃が部隊のまわりに広がる | 画面いっぱいに広がる刃と残像・中心からの光の筋 |
| 命中 | 小さな火花 | 大きな火花・足元からの衝撃波 |
| 画面 | ― | 技名の帯（技名と兵士の名前）・白い閃光・軽い画面の振動 |

- 2体以上を一度に倒すと、倒れた所で順に爆発して「N体撃破！」。
- 戦闘は止めない（技名の帯も表示だけ）。演出の数は上限（effects 80・shots 160）の中で、多いときは細かい火花を省く。
- 端末の「視差効果を減らす」では、振動・閃光・帯のすべり込みを出さない。

## 将来への備え（設計）

- 攻撃の型（`ATTACK_PATTERNS`）：方向（扇・全方位）・長さ・太さ・1本で当たる数・威力・盾を抜けるか・演出をデータで書く。職業スキル・武将の必殺技・奥義は型の名前と倍率を指すだけで使える。ホーミング・分裂・回転する護衛弾は、飛んで当たる弾を足して同じ表から使う。
- 敵の行動（`ENEMY_BEHAVIORS`）：既存の敵の種類を土台に、止まって撃つ・守る・ついて行く、を足す。道を無視して進む敵は、ここに動き方を足す。
- 演出（`combatFx`）は見た目だけで、当たり判定と分けている。1対100のような大人数の場面でも上限の中で省いて動く。
