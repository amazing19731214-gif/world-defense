## 3. 技の共通ルール

### 3.1 発動と装備

- すべて自動発動。時間停止、対象を選ぶ画面、追加の手動ボタンは設けない。射程内に有効な対象がいて、表の条件と待ち時間を満たしたときだけ発動する。
- 職業固有技は現在職だけの自動枠1つ。通常技と上位技は同じ系列で、上位を解放したら通常を置換。両方の効果を足さない。転職すると現在職の技へ切り替わり、元職に戻ると元の段階を使える。
- 閃き技は習得一覧を保持し、その中から**専用の有効枠2つ**を選ぶ案。既存の通常スキル20枠・書装備4冊とは別。空きがある初回だけ自動設定し、満杯なら習得だけ行う。切替は準備中のみ。
- 閃き技は転職後も保持。ただし現在の攻撃方法に合う技だけ発動する。「弓が必要」「回復職が必要」などを表示し、不適合な技は灰色にして残す。衛生兵が攻撃技で攻撃を始めることはない。
- 新しい固有技と閃き技は1兵士につき共通3秒の発動間隔を持ち、同時に条件が成立したら有効枠の閃き技を優先する。通常攻撃・既存スキル・武将必殺技の待ち時間は変えない。
- すべての秒数はゲーム内時間。停止中は進めず、倍速では同じ戦闘結果になる速度で進める。メニュー開閉・転職・部隊移籍で待ち時間を戻さない。

### 3.2 威力・対象・重ね掛け

- 表の **A** はその兵士の通常攻撃の基準威力。攻撃力と常時補正までを含み、会心・居合・突撃・一閃などの一撃倍率を重ねる前の値。**H** は通常治療1回の基準回復量。**M** は回復・盾を受ける兵士の最大HP。
- 「追加0.3A」は通常の一撃をそのまま処理したうえで別に加える分。「通常治療＋0.25H」は元の治療を置き換えず追加する分。既存の通常攻撃・追加攻撃・初撃・回復補正は元の処理を1回ずつ通す。
- 追加ダメージにも防御計算を1回適用。新しい追加攻撃から、連続攻撃・流鏑馬・伝説のビーム/雷/爆発/分身・別の新技を再発動しない。技の発動だけで攻撃回数カウンターを増やさない。追加命中・撃破の経験値は既存の戦闘上限に含める。
- 最初の対象は通常射程内に限定。扇・円・直線の追加対象は表の範囲と人数上限を守る。範囲はワールド座標のpxであり、画面上のpxではない。範囲技の最大n体には主対象も含める。「別の敵n体」は主対象を除いた追加先n体を数える。構造物へは直接ダメージ以外の足止め・弱体を与えない。
- 盾は期限つきの一時HPで、回復・復活・最大HP上昇ではない。同じ技・同じ系統の盾は強い値を採用し、足し合わせず、更新だけを許可する。割合盾の合計は1人あたりMの15%を新技側の上限案とする。既存盾との優先順位は実装前に確定する。
- 新技による減速は最大35%、同系統は強い方だけ。通常敵の短い行動停止は最長0.3秒。ボスの停止・押し戻し・行動妨害は原則無効、代わりの直接ダメージがある技はそれだけ通る。例外を作る場合はボスごとの耐性表を先に用意する。
- 既存の回避40%・会心40%・ダメージ軽減75%・防御無視80%などの上限を超える抜け道を作らない。既存武将の回復支援・魂喰いなどの回復禁止・戦死の永久性を守る。
- 以下の威力・秒数は初期調整案。DPS・耐久の採用基準を満たさなければ、既存能力ではなく新技側を調整する。根拠：R3〜R6・R10。

## 6. 現在の育成頻度の調査と閃き率の根拠

### 6.1 コードで確認できた経験値ルール

- 次レベルまでの経験値は `15 + Lv×15 + max(0,Lv−10)×10 + floor(max(0,Lv−30)^1.5)`。
- 通常防衛戦は戦闘経験が1人1WAVE最大70、生存20は別枠。出撃して生存する兵士の0〜70の戦闘貢献を仮定すると、1WAVE20〜90経験値となる。毎回90を獲得する保証はなく、人数が増えればとどめ・回復機会も分散する。
- 攻城戦・秘境は戦闘経験が基本的に70上限、生還20、勝利時に追加20。1戦最大110を目安にできるが、未出撃・撤退・死亡・主人公の戦死で受取条件が異なる。
- 修練場は敵LvをLとして1単位U=6+2L、戦闘上限70+12L、生存1.5U、最後までクリアすると追加6U。回復や実ダメージなどの実際の貢献を使うため、通常防衛より何度もレベルが上がる場合がある。
- レベルアップ1回ごとに処理する `gainXp` のwhileループがある。一度に複数Lv上がる場合がある。現行の通常・固有・伝説の習得は `fresh`（過去の最高Lvを初めて超えたか）で制限される。
- 通常スキルはLv5・15・40以降20Lvごと、固有スキルはLv30および100Lvごとに30%、伝説は終盤解放後の新規Lvごとに12%。今回の閃きをこれらの抽選へ混ぜない。

根拠：R2〜R4・R7。

## 7. 閃きの抽選・通知・図鑑

### 7.1 抽選手順案

1. `gainXp` の1回の呼出しで上がった各レベルを順に評価する。実際に `onLevelUp(s, fresh)` が受け取る新規Lvだけを対象とする。
2. 生存・現在職・その時点の熟練・必要Lv・未習得・未評価のレベルであることを確認。熟練は現行 `gainXp` が加算した後の値を使う。複数Lvが一度に上がる場合もこの順序を明文化し、通常育成との差を作らない。
3. 候補がなければ習得しない。候補があれば等級の確率で1回だけ抽選。再到達Lv、主人公の死亡後の低Lv育成、書での習得、熟練だけの上昇では再抽選しない。
4. 抽選の評価位置と当選結果を、兵士側の閃きデータとして保存する。確定前は技を有効化せず、図鑑にも成功として記録しない。
5. 保存確定後に習得・空き枠への設定・通知・戦歴・図鑑を反映する。複数兵士・複数Lvの同一フレームの更新はまとめて確定し、localStorageへの大量の同期書込みを避ける。

### 7.2 💡表示と技の演出

- 習得確定時、ゲーム画面内に **「💡 兵士名：技名を閃いた！」** を表示。兵士の近くに小さな電球を0.7秒表示し、技名は読み取れる時間の短い吹き出しにする。画面外の大きなバナーで戦場・操作ボタンを押し下げない。
- 既存のレベルアップ通知とは別イベントとしてキューへ入れ、同じ兵士のレベル通知へ統合できるようにする。大量の同時習得は最大3件を順に表示し、残りは件数表示＋履歴で読めるようにする。時間停止はしない。
- 戦闘中は表の剣筋・槍線・包帯・矢・網などを使い分け、発動した兵士に小さな対応アイコンを付ける。通常のレベルアップや伝説の雷演出と取り違えないようにする。
- 判定と描画を分ける。新技の短いエフェクトは同時24件までを初期目標にし、既存のeffects上限80・shots上限160を超えない。同じ部隊の同時効果はまとめて描画する。エフェクト省略時もダメージ・回復は省略しない。
- 発光・揺れを抑える表示では電球・技名・静止した軌跡に置換する。配属兵の画像は当面既存素材を利用できるが、各技の軌跡と形まで単なる色替えにはしない。

### 7.3 図鑑

- 「スキル」内に通常・職業スキル・職業固有技・💡閃き技・伝説の分類を表示。既存の5カテゴリや既存発見IDを再解釈しない。
- 閃きは自然習得または秘伝書での継承を確定した時点で発見。未発見は「???」。閲覧だけ、条件に到達しただけ、保存失敗しただけでは発見扱いにしない。
- 発見後は転職・戦死・引退・「最初から」でも記録を保持。元の職、等級、発動適性、効果、待ち時間、自然習得条件、継承の必要Lv、演出説明を表示する。
- 図鑑への転記が失敗しても、確定済みの兵士・秘伝書・引退記録から復元できる発見記録を正本に含める。戦死・売却後にも消えないよう、現在の所持品だけから再計算しない。根拠：R8・R11。

| 閃きの習得・設定・評価済みLv | 兵士ごとの `insight: {version, seed, evaluatedMaxLevel, known, equipped}` | `learned` / `skills` / `legend.stats` / `legend.abil` と別。`known`は登録済み21IDの集合、`equipped`はその部分集合で最大2つ |
| 閃き秘伝書 | `forge.insightBooks` と専用の連番 | `forge.books` と `forge.legendBooks` に混ぜない。種別付きUIDと元兵士/技の由来を持つ |
| 図鑑発見 | 保存形式を拡張した発見集合 | 既存スキルIDとの衝突を防ぐ専用ID。確定した発見の正本と表示用図鑑を分ける |
| 戦死・復活 | 英霊の `snap` に同じ閃きデータを含める | 復活の書で戻る兵士は習得・評価位置・seedも引き継ぐ。別人として再雇用した新兵には新しいseedを割り当てる |

- 既存の**書4冊は能力値・特殊能力の装備枠**。閃き秘伝書は「消費して技を習得する」道具とし、5冊目の装備にしない。4冊を装備中でも閃き技の継承・有効枠2つを利用できる案。
- 閃き秘伝書は技IDと由来だけを継承し、能力値・特殊能力の数値を持たせない。使ってもレベル・熟練・ステータスポイント・伝説の能力は増えない。
- 閃き秘伝書の保管上限は200冊を暫定案とする。既存の伝承書200冊とは別。満杯時は引退を確定する前に止め、書を捨てて引退だけ成功させない。
- 旧セーブで `insight` がなければ未習得とし、seedを保存してから新しい抽選を開始する。過去Lvぶんの抽選や一括プレゼントはしない。初期の評価位置は既存の `bestLevel` を基準とする。
- `cleanJob`、`pickSaved`、`restoreRoster`、英霊記録、復活、主人公の再出発、兵士の解散・引退・セーブ読込をすべて調査して拡張する。未知ID、重複ID、範囲外の評価Lv、過剰な枠数、不正UIDは読み込み時に除く。
- 下位バージョンへ戻すと新規フィールドが削除される可能性がある。下位版での継続プレイまでは互換保証せず、導入前のバックアップと新旧形式の移行試験を実装条件にする。既存v80の項目の意味や値は書き換えない。

### 8.2 二重抽選・保存失敗・再読込の対策

- 評価済み最高Lvを通常の `bestLevel` と別に保持する。新技のために兵士の現在Lv・XPや防衛チェックポイントを戦闘中の値へ丸ごと更新しない。保存するのは追加の閃きデータとその確定記録だけ。
- 保存済みseed・兵士の一生を区別するID・到達Lv・抽選ルール版から同じ乱数を再現できるようにし、保存前の失敗・再試行で確率を引き直さない。通常の戦闘乱数や伝説の乱数と分離する。
- 1つの到達Lvイベントを1回だけ扱う。主人公がLv1から再出発してもseed・評価位置・習得済み集合を保持。復活の書でも同じ一生の評価位置を戻す。転職で過去のLvを再抽選しない。
- 現行の `worldDefense.bookTransaction.v1` の先行ログ方式を利用し、**兵士の閃きデータ・書の増減・発見の正本を同じ確定単位**にする。現行の許可キーは武将・兵士・征服の3キーなので、図鑑を直接同時更新するなら許可キーと旧形式の読込も拡張する必要がある。未決定のまま別保存にしない。
- 推奨は兵士側の新形式に「確定済みの閃き発見集合」を含め、既存図鑑キーへは再構築可能な転記を行う方式。未転記でも発見を失わず、現在の許可キーを増やさずに済む。新形式の読込ではこの集合を消さない。
- 確定ログを保存できなければ習得・消費・引退・図鑑反映を行わず「保存待ち」を表示。同じ未確定イベントを再試行し、成功通知を先に出さない。ログ確定後の通常キーへの転記失敗では、ログを正本として読んで次回に復旧する。
- 完全に保存できない環境では、ブラウザを閉じた後まで未確定イベントを保持することは保証できない。未確定を習得成功と扱わず、保存済みseedによる同じ抽選値と重複ID検査で再試行時の増殖を防ぐ。セーブ全体を手動で過去版へ差し戻す行為の防止やオンライン用の不正防止は今回の範囲外。

根拠：R8〜R11。保存の形を先に固め、演出より先に障害テストを通す。

## 9. 指導員による閃き技の継承

1. 現行どおり、生存・在籍・Lv100以上・主人公以外・準備中の兵士だけが指導員になれる。戦闘中・修練場挑戦中は不可。
2. 引退画面に既存の通常スキル/能力値/特殊能力と「💡閃き技」を分類して並べる。**残せる本命は全分類を通じて1つ**。既存1冊に閃き1冊を追加する方式にはしない。既存の0.1%の超秘伝書ボーナスは別の現行仕様として維持する。
3. 閃き技を残す場合は、その兵士が確定保存済みの `insight.known` で持つ技を1つ選ぶ。転職前に閃いた技でもよく、今有効枠に入っている必要はない。元職の熟練度を再要求して選べなくすることはしない。
4. 新しい職業固有技の自動枠は継承対象外。既存18個の職業スキルは現行の継承を維持する。
5. 受取側は生存・保存済みの兵士で、表の必要Lv（10/30/100）を満たすこと。元職の熟練度は不要とする案。現在職が不適合でも習得一覧へ保持できるが、使用前に発動適性を満たす必要があることを確認画面に表示する。
6. 受取側が同じ閃きIDを持っていれば使用不可、書は消費しない。有効枠2つが満杯でも習得だけ可能とし、現在の技を勝手に外さない。
7. 引退は「兵士の在籍解除・装備と4冊の書の返却・閃き秘伝書1冊の発行・指導員記録」を一緒に確定。使用は「書UID1つの削除・受取兵の習得追加・発見」を一緒に確定する。
8. 同じUIDの書を2回使用しようとしても、存在検査・習得集合・確定処理中の再入防止で拒否する。読込時にもUIDを重複排除。ログの再適用は加算処理ではなく確定済み状態の転記として行う。
9. 退役した兵士を英霊名鑑へ追加しない。死亡と退役を区別し、復活の書で退役者を戻して同じ本人から再発行する道を作らない。継承を受けた別の兵士が後にLv100で引退して次世代へ1冊を残すことは正規の継承とする。
10. 引退・使用のどちらも保存失敗時は元の兵士・装備・書・有効枠へ完全に戻す。発行・消費・所持数だけを成功表示しない。

根拠：R9・R10。最大冊数、未保存の兵士、同時クリック、リロード、倉庫満杯、主人公、英霊からの復活を受入試験へ含める。

## 12. バランスと受入基準

- 既存スキルを取り外して新技を強く見せる比較はしない。現行装備・武将・既存スキルをそろえた同条件比較を行う。
- 基本職も上級・最上級の下位互換だけにはしない。通常技の早い解放、短めのCD、射程・盾・治療の役割を残す。
- 最上級職はLv100/150前後・Lv500/1000・終盤の伝説ありで確認する。旧職の基礎値やスキルを弱体化して帳尻を合わせず、新職の係数と新技の追加分を調整する。
- 新技だけを追加したときの継続DPS/有効回復/被ダメージの改善は、同職の旧能力に対し通常技でおおむね+5〜10%、上位技で+10〜15%、閃き2枠を含めても+25%程度までを初期の検証目標とする。盾・妨害の価値はDPSだけに換算せず、漏れた敵・生存数・撃破時間でも測る。

- 20/60fps、停止/倍速、味方死亡/撤退、対象が消える瞬間でも二重命中・死者回復・負のHP/NaN・無限連鎖が起きないこと。
