# 第五章「中東・インド」（v95 / W5）

「🌏 世界」から進めるシングルプレーの新章です。東南アジア12拠点の制覇で解放します。過去に制覇した記録がある場合は、領土を失っても章の解放を維持します。

出陣には隣接する領土が必要です。入口は東南アジアの「海峡諸港」から「西洋航路」でつながるマラバール。旧セーブの東南アジア制覇からも解放でき、兵士・武将・装備・書・成長は引き継ぎます。解放やセーブ移行だけでは報酬を配りません。

地名を参考にしていますが、城名と勢力はゲーム独自の設定です。日本68か国の天下統一、裏ボス討伐の完全クリアとは別に記録します。中東制覇だけで世界征服にはなりません。続くヨーロッパ・ロシアは v96 で追加しました（[第六章・第七章ガイド](EUROPE_RUSSIA_CHAPTER_GUIDE.md)）。

推奨レベルは入場制限ではありません。ホルムズからメソポタミアへの分岐、レバントからナイルへの進軍も可能ですが、章制覇には全12拠点が必要です。未知の拠点は周辺の領土を得ると発見します。一度発見した拠点は失地後も見えます。

- **砂漠**：道に沿った距離260〜460の区間だけ、味方の進軍速度が85％。HPの自動減少や攻撃・回復間隔への罰則はありません。区間を抜ければ元に戻ります。道には砂色と「砂漠 速度85%」の札を表示します。
- **渡河**：既存の仕組みと同じく、部隊ごとに1回1.5秒待ちます。攻撃・回復・被弾は継続します。停止・倍速は同じゲーム時間で処理します。
- **要塞都市**：既存の堅城の仕組みで城HPと防衛塔を増やします。重装騎兵は高HPと装甲、弩兵は長射程を持ちます。騎兵の接近、前衛の防御、回復、貫通や装甲無視を組み合わせてください。ナイルには名将の守備隊がいます。

各城の初回制圧でガチャ券1枚、ナイルのみ2枚。全12城で計13枚に加えて、章の初回制覇で12枚、合計25枚です。演習や再占領では再配布しません。章報酬は領土・兵士の成長・受領印と同じ保存ログで確定します。確定ログの保存失敗時は未保存を知らせ、確定後の転記失敗は次回読込で復旧します。

反撃は同じ章の隣接拠点から来ます。中東から東南アジアや日本への反撃はありません。反撃は防衛10ウェーブで撃退、敗北すると対象領土を失います。海外制圧で既存の国内領土ボーナスや通常防衛・修練場の敵設定は変わりません。

難易度は東南アジアから続く平方根の成長曲線を使います。守備兵・防衛塔の基礎倍率は `38 × √(敵Lv / 625)`、城HPは `43,775 × √(敵Lv / 1100) × 堅城補正` を100刻みに丸めます。レバントは槍と鉄砲の組み合わせを考慮し、守備兵・塔の基礎倍率を0.97倍にしています。通常の制限時間は180秒です。

進行・報酬・保存のテストは勝敗を指定するものと、実際に時間を進めて戦う模擬戦を分けて確認します。推奨Lvは目安で、装備・職業・編成・戦歴によって結果は変わります。iPhone Safari実機での確認は行っていません。
