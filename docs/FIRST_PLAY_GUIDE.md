# はじめての操作ガイド（v126）

新規プレイヤーが最初の防衛を始めるまで、既存の「次の目標」に操作ボタンと短い説明を追加します。操作を制限するチュートリアルではなく、途中で案内を終了して自由に遊べます。

1. **建設**：引き出しを開き、弓の塔を案内。塔を選んでマップの草地をタップします。
2. **雇用**：部隊の引き出しから既存の「＋ 雇う」を押します。現在は最初の1人が無料で、以降の基本料金は2,500Gです。兵種抽選や費用は変更しません。
3. **配置**：待機中の部隊を選び、道をタップ。草地と道に金色の目印を描きます。目印は通常の配置判定を通る候補だけです。
4. **戦闘**：既存のウェーブ開始処理へ進み、戦闘中は自動攻撃・城のハート・勝利時の自動保存を説明します。

最初のWAVEクリア後は従来のガチャ・WAVE 3・世界へ進む目標に戻ります。攻城戦・修練場・探索・サバイバルでは初回案内と目印を表示しません。既存プレイヤーへの自動表示はありません。

案内の終了状態だけを既存の表示設定 `worldDefense.ui.v1` の `firstGuideHidden` に追加します。部隊・塔・育成・戦歴・領土などの保存形式、料金、戦闘バランス、戦闘の保存確定点は変更しません。再読込時の準備状態は既存のチェックポイントに従います。

「情報 → はじめての遊び方・保存について」から、操作・回復・探索の村での仲間加入・ブラウザへの保存・最初からとデータ消去の違いをいつでも確認できます。最初のWAVEをまだクリアしていない場合は、現在の状態から案内を再表示できます。進行をリセットする処理はありません。
