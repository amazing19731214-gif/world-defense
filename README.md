# world-defense
Tower Defense Game

ブラウザで遊べるタワーディフェンス。配布物は画像込みの単一ファイル `index.html` です
（GitHub Pages ではこのファイルをそのまま公開します）。

開発状況と今後の計画は [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md) にまとめています。

## スマートフォンの画面（v27）

ゲームの中身は変えず、iPhone で遊びやすいように画面を整えた。
- **上の帯**：城HP・所持金・ウェーブ・配置数・📖スキル を1行にまとめ、スクロールしても画面の上に残る。スマホではタイトルを隠してマップを広く表示。
- **塔・部隊のパネル**：画面の下から出るシート（見えている高さの6割まで）。中身が多いときはパネルの中だけスクロールし、「✕ 閉じる」は上に残る。
  開いている間はページの下に同じ高さの余白を足すので、ほかのボタンもスクロールすれば必ず押せる。
- **武将の直接配属**：部隊（または塔）を押す → 「👤 武将を選択」 → 武将を押す、の3タップで配属。一覧は配属できる武将が先で、名前・レア度・★・役割・配属先・負傷を表示。
  配属中の武将は「外す」、ほかに配属中の武将は「移す」。決まり（負傷中は不可・同じ武将は1か所だけ）はこれまでと同じ。
- **部隊のパネル**：部隊名・状態・人数・平均Lv・HP・足止め・武将、ボタンは 撤退（待機中なら📍配置）・治療・＋補充・📋兵士。兵士ごとの詳細は「▼ 兵士の詳細」で開く。
  待機中の部隊を押すとパネルは小さくなり、そのまま道を押せば配置できる。
- **部隊ボタン**：横1列（入りきらなければ横スクロール）。「第一」と「10人·出陣中」のように人数と状態。部隊の列の見出しは「配置 n/4｜保有 n/4」（上限は設定から）。
- **画面の高さ**：Safari のアドレスバーやキーボードで見えている高さが変わると、visualViewport からシートの高さ・位置を合わせる。`viewport-fit=cover` と `env(safe-area-inset-*)` で、ホームバーやノッチに隠れない。
- `node tools/test-mobile.mjs` で 375×667・390×844・430×932・375×560 の表示と、部隊からの武将の配属を確認できる。

## 混成部隊（v26）

- 1部隊にいろいろな兵種を入れられる（10人まで）。兵士は1人ずつ自分の兵種として戦う（弓兵・鉄砲兵は遠くを射る、衛生兵は回復、騎兵は突撃、足軽・槍兵は近接）。
- 「📋 編成」の**新兵補充…**で、補充する兵種を1人ずつ選べる。**移籍**も兵種に関係なくできる。
- 部隊の決まり：
  - 足止め：生きている兵士の兵種の中で一番多い数（槍兵3・足軽2・騎兵1）。槍兵が全員倒れると下がる。
  - 敵の騎兵：部隊に騎兵がいれば止められる。
  - 撤退：一番遅い兵士に合わせる（騎兵だけの部隊は速い）。
  - 主な兵種：一番人数の多い兵種。部隊ボタンの絵と、武将の得意兵種の判定に使う。兵種が混ざると部隊名は「第一部隊（混成）」。
- 攻城戦はもともと兵士ごとに戦うので、混成部隊のまま出撃する。
- 保存データで部隊と違う兵種の兵士も、混成部隊として読み込む（以前は読み込まなかった）。
- `node tools/test-mixed.mjs` で確認できる。

## 防衛戦と攻城戦で同じ4部隊（v25）

- 部隊は**第一〜第四部隊の4つ**だけ（1部隊10人まで）。防衛戦で道に出す部隊と、攻城戦で出撃する部隊は同じ。
  - 新しく雇うと5人（費用も5人分）。「編成」の新兵補充で1人ずつ10人まで増やせる。
  - 部隊は空いている枠（第一→第四）に入る。解散すると枠が空く。部隊名は「第一部隊（槍兵）」のように枠と兵種で表す。
  - 攻城編成で選ぶのは**武将だけ**（防衛の配属とは別のまま）。兵士の入れ替えは「📋 編成」で行う。攻城戦に出るのは、ウェーブをクリアして保存された兵士。
- 以前の保存データ（5人×最大8部隊）は、読み込むときに同じ兵種の部隊どうしを10人ずつにまとめる。兵士は1人も失わない。
  兵種が5種類以上あって4部隊に収まらないときは、枠外の「予備隊」として残り、解散などで枠が空くと入る（予備隊がいる間は新しく雇えない）。
- 防衛戦の部隊パネルは10人を5人ずつ2段で表示。道の隊形も10人分。
- 「最後の生存者」は、4人以上の仲間が戦死して1人だけ残ったときに付く。
- 模擬（塔4基・4部隊・20ウェーブ）：4部隊×5人より4部隊×10人のほうが約3ウェーブ長く持つ（Lv10でウェーブ17 → 20）。
- `node tools/test-formation.mjs` で、以前の保存データのまとめ方・枠・攻城編成を確認できる。
## タンク・ヒーラーの役割調整

- 忠勝：最大HP+30%と常時軽減、必殺技は周囲40%軽減。氏康：防御+25%・足止め+1、必殺技は全攻撃を吸収する盾。元康：最大HP+20%、半分以下で軽減。
- 兼続：衛生兵の回復量+30%・間隔-20%、救護陣は即時20%と継続回復。塔配属では衛生兵の回復射程を支援。
- 秀吉：周囲の衛生兵の回復量+20%、塔では生存兵の継続回復。必殺技は周囲25%回復と衛生兵の回復間隔-30%。従来の補充・修理割引と撤退技は置き換えます。
- 幸村のタンク能力、半兵衛の緊急回復、義景の持久戦向け回復を維持。最大HP増加による無料回復や、戦死者の復活はありません。
- 数値・範囲・持続時間は [docs/WARLORD_SKILLS.md](docs/WARLORD_SKILLS.md)。今回の調整は防衛戦向けで、攻城戦の既存補正と専用必殺技は維持します。

## 攻城戦の武将の必殺技（v24）

- 攻城編成で武将を付けた部隊は、攻城戦の画面下の**必殺技ボタン**で技を使える（出撃したらすぐ使える。再使用までの秒数は防衛戦と同じ）。
- 防衛戦の必殺技（30種）を、攻城戦では5つの型にまとめた（数値は `SIEGE_SKILL`、対応表は `SIEGE_SKILL_OF`）。威力は部隊の兵士の攻撃力の合計に掛ける。
  | 型 | 効果 | 武将の数 |
  | --- | --- | --- |
  | 一撃 | 前方の敵1体（守備兵 → 塔 → 城の順）へ 400% | 8 |
  | 範囲攻撃 | 部隊の半径150の守備兵・塔すべてへ 150% | 6 |
  | 鼓舞 | 半径160の味方部隊の攻撃 +40%（10秒） | 2 |
  | 守りの陣 | 半径160の味方部隊の被ダメージ -50%（10秒） | 9（タンク型の幸村・忠勝・氏康を含む） |
  | 手当て | 半径160の味方の兵士を最大HPの50%回復（戦死者は戻らない） | 5 |
- 届く敵がいないときは使えず、再使用の時間も減らない。スキル一覧と攻城編成の武将選びに、攻城戦での効果を表示。
- 模擬（4部隊×10人・Lv5・甲斐）：技なし 20人戦死・73秒 → 技あり 18人戦死・65秒。助けにはなるが、育成の代わりにはならない強さ。
- `node tools/test-siege-skill.mjs` で確認できる。

## 部隊ボタンですぐ配置・操作ボタンの並び替え（v23）

- 画面の並びを、よく使う順に変えた：**マップ → ▶ ウェーブ開始（左に大きく）・速度・停止 → 部隊 → 塔 → ガチャ・武将・兵士・攻城編成・最初から**。
- 保有している部隊（最大8）を、塔ボタンの下に**部隊ボタン**（兵種の絵・番号・人数・平均Lv）で並べる。
  - 待機中の部隊：ボタン → 道をタップ の2タップで配置（もう一度押すと取り消し）。
  - 出陣中の部隊：緑の枠で「出陣中／撤退中」。押すと部隊パネル（撤退・治療・武将）を開く。
  - 撤退直後・兵士のいない部隊は薄く表示（押すと理由を表示）。戦闘中の撤退完了・全滅もすぐ反映。
- あまり使わない雇用ボタン（足軽〜騎兵）は「＋ 雇う」の中に畳んだ。部隊がまだ無いうちは開いたまま。
- 「📋 編成」（補充・移籍・解散・治療）はこれまでどおり。
- `node tools/test-quickdeploy.mjs` で部隊ボタン・畳める雇用ボタン・390px の表示を確認できる。

## 武将30人の役割別スキル（v21）

- 防衛戦の全武将のパッシブを「部隊用」「塔用」に分け、兵種の得意・前線維持・狙撃・救援・兵站・妨害などに変更しました。武将ID・レア度・所持枚数・画像・保存形式はそのままです。
- 必殺技はボタンを押すと対象を自動で選んで発動します。戦闘を止める対象選択はありません。発動できる対象がいない場合は再使用待ちを消費しません。
- 前列交代、致命傷を1回耐える守り、突撃・救援移動、毒、待ち伏せ、罠、救護陣、射撃盾、補充・修理割引などを追加しました。再配属で回復や初撃を取り直せず、戦死者も復活しません。
- 詳細な数値・共通ルールは [docs/WARLORD_SKILLS.md](docs/WARLORD_SKILLS.md) を参照してください。スキル一覧画面も同じ設定に更新しています。
- `node tools/test-warlord-roles.mjs` で30人の両配属先での発動と個別効果・対象選択・再配属・時間進行を確認できます。

- 攻城戦は同時期に追加された別システムのため、従来の武将の攻撃・防御補正を維持します。今回の役割別パッシブ・対象指定必殺技は防衛戦向けです。攻城戦の必殺技は v24 で5つの型にまとめて実装しました。

## 奪い返し（NPCの反撃・v21）

- 攻城戦で新しい国を取ると、50%の確率で**隣の敵国が反撃**してくる。狙われるのは境目の領土（自国以外で、まだ取っていない国と隣り合う国）。
- 反撃中は画面上部にお知らせ（あと何ウェーブ）を出す。**防衛戦でウェーブ10までクリア**すれば撃退（🎴 ガチャ券 +1）。
  その前に**ゲームオーバー**になるとその国を奪われ、特産の効果も消える（また攻略できる国に戻る）。
- 「最初から」でやり直しても反撃は続く（奪われもせず、撃退にもならない）。反撃中は新しい国を攻められない（演習はできる）。
- 反撃は `worldDefense.conquest.v1` の `counter` に保存。数値は `COUNTER`（確率・守るウェーブ数・報酬）。

## 領土（7か国・v19）

- 自国は**三河（岡崎城）**。自分の領土の**隣の国だけ**攻められ、城を攻め落とすとその国が領土になる（地図は使わず国名の一覧）。
  | 国 | 城 | 隣の国 | 強さ（耐久） | 初回報酬 |
  | --- | --- | --- | --- | --- |
  | 三河 | 岡崎城（自国） | 尾張・美濃・遠江・信濃 | — | — |
  | 尾張 | 清洲城 | 三河・美濃 | ×1.0（1600） | 🎴3 |
  | 遠江 | 曳馬城 | 三河・駿河・信濃 | ×1.1（1800） | 🎴3 |
  | 美濃 | 稲葉山城 | 尾張・三河・信濃 | ×1.25（2200） | 🎴4 |
  | 駿河 | 駿府城 | 遠江・甲斐 | ×1.35（2400） | 🎴4 |
  | 信濃 | 深志城 | 美濃・三河・遠江・甲斐 | ×1.45（2600） | 🎴5 |
  | 甲斐 | 躑躅ヶ崎館 | 駿河・信濃 | ×1.6（3000） | 🎴5 |
  - 強さは守備兵の体力・攻撃と防衛塔の攻撃に掛かる。奥の国ほど守備兵が多い（騎兵・大将の追加）。
- 攻城編成の画面の「🗾 領土」から攻略目標を選ぶ（攻められる国の城、または領土の城を演習に）。目標は保存され、攻め落とすと次の国へ移る。
- 7か国を統一すると 🎴 ガチャ券 +10（1回だけ）。統一後は演習として攻められる。
- 保存は `worldDefense.conquest.v1`（城ごとの占領・挑戦回数・勝利数、選んだ目標、統一）。以前の保存データ（清洲城だけ）もそのまま読める。

## 清洲城の攻略（v18・Phase 5）

- 攻城戦の相手は城ごとのデータ（`NPC_CASTLES`）になった。最初の城は**清洲城（尾張）**（耐久1600・防衛塔4基・守備兵17人）。
  城の並び `CASTLE_ORDER` の、まだ占領していない最初の城が攻略目標になる（7か国へ広げるときは城を足す）。
- 攻城編成の画面に攻略目標（城名・国・耐久・塔・守備兵・報酬・占領状況）を表示。出陣ボタンにも城の名前を出す。
- 勝利すると**占領**し、保存する（キー `worldDefense.conquest.v1`：城ごとの占領・挑戦回数・勝利数）。
  - 初めて攻め落としたときだけ報酬（清洲城：🎴 ガチャ券 +3）。
  - 占領済みの城は「演習」として何度でも攻められる（報酬・占領なし。経験値・戦死・負傷はふだんどおり）。
  - 撤退・敗北では占領しない（挑戦回数だけ増える）。
- 結果画面に占領の知らせと報酬を表示する。

## 攻城戦（v17・Phase 4 基本システム）

- 「⚔️ 攻城編成」画面の「⚔️ 出陣（攻城戦）」で始める（防衛のウェーブ中は不可）。防衛戦の状態はそのまま止まり、終わると戻る。
- 防衛戦の地図を使い、左から味方が進軍、右端の城がNPCの城（耐久1600）。
  - NPC側：防衛塔4基（弓2・鉄砲・大砲）と守備隊（足軽・槍兵・弓兵・大将の赤い兵）。
- 第一部隊から**10秒ごとに出撃**し、自動で戦う。進軍の速さは部隊で一番遅い兵に合わせる（騎兵だけの部隊は速い）。
  - 守備隊の手前で止まって戦い、届く塔や城を攻撃する。衛生兵は攻城の部隊を回復する。攻城編成の武将は部隊の攻撃・防御を上げる。
- **勝利**：城の耐久を0にする。**敗北**：全部隊が倒れる・全軍撤退・3分の時間切れ。
- 経験値・戦死・負傷は防衛戦と同じ：戦闘中の経験値（1人70まで）＋生還ボーナス20（勝利でさらに+20、撤退はなし）。
  戦死はその場で保存（英霊名鑑にも）、部隊が全滅すると武将は負傷。結果は1回だけ保存する。
- 数値は `src/index.template.html` の `SIEGE_BATTLE`。占領・NPC城の攻略の完成は Phase 5。

## 武将・兵士のスキル一覧

## 騎兵（v16）

- 兵士部隊に**騎兵**（騎馬隊・5人140G）を追加。味方の兵種は6種類（足軽・槍兵・弓兵・鉄砲兵・騎兵・衛生兵）になった。
  - 能力：HP85・攻撃11・防御6・間隔1.0秒・射程60・足止め1。
  - **敵の騎兵を止められる唯一の兵種**（ほかの兵種では敵の騎兵は止まらない）。
  - **突撃**：新しい敵への最初の一撃が2倍。
  - **撤退が速い**：1.5秒（通常は3秒）。
  - **槍兵に弱い**：敵の槍兵から受けるダメージが1.5倍。
  - 進軍の速さ `march: 1.8` は攻城戦（Phase 4）で使う（防衛戦では部隊は道の一点に配置するので使わない）。
- スキル：突撃上手（突撃×2.5）・人馬一体（槍兵からの追加ダメージを半分）・鉄壁・連続攻撃・敵将狙い・弓回避・生存本能。固有は「一騎当千」（攻撃+20%）。
- 画像は一覧画像から切り出したコマ（待機・攻撃・戦死）。雇用ボタンは4列にそろえた。

## 鉄砲兵・衛生兵（v15）

- 兵士部隊に**鉄砲兵**（鉄砲隊・5人150G）と**衛生兵（陣中医）**（陣中医隊・5人120G）を追加。防衛塔の「鉄砲の塔」とは別。
  - 鉄砲兵：HP40・攻撃20・間隔2.4秒・射程165・足止めなし（弓兵：HP45・攻撃9・間隔1.2秒・射程150）。発砲時に閃光と煙。
  - 衛生兵：HP55・攻撃なし。範囲120の味方のうちHPの割合が最も低い1人を3秒ごとに5回復（自分は対象外・最大HPを超えない・戦死者は蘇生しない）。回復時に緑のエフェクト。
  - 衛生兵は治療1回で経験値2（戦闘中の上限70/ウェーブの対象）＋生存ボーナスで成長。
- スキル：鉄砲兵は速射・遠矢・精密射撃（攻撃+15%）・敵将狙いなど、固有「三段撃ち」（間隔-20%）。
  衛生兵は治療上手（回復+25%）・早手当（間隔-15%）・鉄壁・弓回避・生存本能、固有「名医」（回復+40%）。
- 画像：鉄砲兵・衛生兵・騎兵の一覧画像から、各コマを切り出して背景を透過した（`assets/units/frames/<兵種>_<動き>.webp`）。
  - 衛生兵のボタン・立ち姿は `assets/units/medic.webp`（待機のコマ）。
  - ゲームで使うコマは manifest の `unitFrames`：鉄砲兵は待機・攻撃（撃つ瞬間に銃口の火）・戦死、衛生兵は待機・戦死。
    コマは待機の絵を基準に同じ倍率で描く（攻撃のコマは体の位置をそろえる）。
  - 歩行・リロード・負傷・治療のコマと、騎兵の全コマは保存だけで、まだ使っていない（騎兵は Phase 3 で使う）。
- 兵種は `SOLDIER_TYPES` に追加するだけで、雇用メニュー・兵士名簿・攻城編成に出る（騎兵も同じ方法で追加できる）。

## 攻城部隊編成（v14）

- 「⚔️ 攻城編成」で第一〜第四部隊（並び順＝将来の攻城戦の出撃順）を編成する。攻城戦の戦闘処理・領土はまだない。
- 各部隊に兵士10人・武将1人まで。同じ兵士・同じ武将は1部隊だけ（「移す」で別の部隊へ移動）。
- 選べる兵士は、兵士の保存データにいる生存兵（ウェーブをクリアして保存された兵士）。戦死すると編成から自動で外れる。
- 武将は所持している武将から。負傷中は配置できない。防衛側の配属（塔・部隊）とは別の計画なので、防衛で使用中の武将も置ける。
  編成後に負傷した武将は「負傷中・出撃不可」と表示する（編成には残る）。
- 保存キー `worldDefense.siege.v1`：兵士・武将のIDと並び順だけを保存（能力・経験値はコピーしない）。読み込み時に、戦死・存在しない兵士、所持していない武将、重複を除く。
- 兵種は `SOLDIER_TYPES` から表示するので、兵種（鉄砲兵・騎兵・衛生兵など）を追加すれば編成画面の絞り込み・内訳にそのまま出る。

## 兵士の育成・命名・スキル（v13）

- 兵士は1人ずつ個別IDで管理し、**ゲームをまたいで残る**（保存キー `worldDefense.soldiers.v1`）。
  - 保存するのは「ウェーブをクリアした時点の生存兵」。新しいゲーム（最初から・再読み込み）では待機中・HP満タンで戻る。
  - 戦死はその場で保存データから外す（再読み込みしても復活しない）。クリアしていないウェーブの経験値は残らない。
- 経験値：攻撃・撃破（戦闘中は1人1ウェーブ70まで）＋ウェーブを生き延びた生存ボーナス20（1ウェーブ1回だけ）。最大Lv30。
- Lv5・Lv15：兵種に合うスキルをランダム習得／Lv10：名前を付けられる（10文字まで・後から変更可）／Lv20：精鋭兵（小さな能力ボーナス）／Lv30：30%で固有スキル。スキルは最大3つ。
  - 槍の達人（攻撃+12%）・鉄壁（被ダメージ-10%）・連続攻撃（15%で追加攻撃）・弓回避（遠距離の被ダメージ-25%）・生存本能（HP3割未満で撤退を試みる・成功率60%）・敵将狙い（大将へ+30%）・速射／遠矢（弓兵）
  - 固有：不屈（足軽）・槍衾（槍兵）・百発百中（弓兵）。城攻め名人は将来の攻城戦用（まだ習得しない）
  - Lv10を超えた分の能力の伸びは半分（強くなりすぎない）
- 部隊パネル（と編成画面）の「🩹 治療」：ウェーブの合間に、部隊の生存兵のHPを満タンにする（雇用費×60%×減ったHPの割合／人。戦死者は対象外）。
- 生存本能で撤退した兵士はそのウェーブの間だけ戦場を離れ、次の戦闘から使える。
- 「🪖 兵士」で兵士名簿（名前・兵種・Lv・経験値・スキル・戦歴、Lv10以上は命名）と**英霊名鑑**（名前付きの兵士の戦死記録。復活はできない）。
- **武将の負傷**：配属先の塔が破壊される・部隊が全滅すると、武将は死なずに負傷。その後3ウェーブは塔にも部隊にも配属できず、4ウェーブ目から復帰。
  残りはウェーブをクリアしたときだけ減る（負けた・やり直したウェーブでは減らない）。負傷は武将の保存データに残る。
- 数値は `src/index.template.html` の `SQUAD_RULES` / `SOLDIER_SKILLS` / `RANKS` / `HERO_RULES.injuryWaves`。

## 敵兵の攻城（v12）

- 敵は赤い甲冑の戦国の兵5種：弓兵・足軽・槍兵・騎兵・大将（味方の兵種と同じ。将来の攻城戦でも共通に使う）。
  画像は兵種ごとに移動・攻撃・戦死のコマを個別のファイルにしたもの（`assets/enemies/`）。
  内部ID（goblin=足軽 / knight=槍兵 / wolf=騎兵 / dragon=弓兵 / boss=大将）は互換のため以前のまま。旧 slime は足軽扱いで、出現しない。
- 敵兵は**道の上を進んだまま**、届く範囲の防衛塔を攻撃する（道を外れて塔へは向かわない）。届かなければ城へ進む。
  - 足軽・槍兵：近くの塔（道から約76〜92まで）／弓兵：遠距離（130）／騎兵：塔への攻撃は弱く、足止めできない
  - 大将：塔に大きな損害。塔の前で最長5秒立ち止まって攻撃し、その後また城へ進む
- 足止めされた敵兵は部隊と戦い、塔は攻撃しない（部隊を置くと塔を守れる）。
- 塔の耐久：弓220・大砲300・鉄砲260・水攻め240（強化でLvごとに+35%）。塔の上に耐久バー、被弾でゆれと木片。
- 耐久0で破壊（土煙と石の演出）。そのウェーブ中は攻撃できず、強化・売却・武将配属も不可。武将は死なず未配属に戻る。
  ウェーブ終了でがれきを片付け、同じ場所に建て直せる（返金なし）。
- 耐久は自動回復しない。ウェーブの合間に塔パネルの「🔨 修理」（建設費×50%×減った割合）。
- 数値は `src/index.template.html` の `ENEMY_VS_UNIT` / `TOWER_HP`。
- 部隊パネルの空いた枠に「＋補充」（ウェーブの合間に新兵を1人雇用）。

## 防衛塔（v10）

戦国時代に合わせた4種類の防衛塔です。

| 塔 | 価格 | 特徴 |
| --- | --- | --- |
| 弓 | 100G | 攻撃間隔が短い |
| 大砲 | 180G | 範囲攻撃（爆発） |
| 鉄砲 | 220G | 高威力・長射程。銃弾と発砲煙の演出（以前の「魔法」と同じ能力値） |

## 戦国武将とガチャ（v9）

**戦国武将**はガチャで獲得する特別なキャラクター、**一般兵士**はゴールドで雇用して育成するキャラクターです。

- 武将は30人（v11で20人追加）。
  - SSR（5人）：織田信長・武田信玄・上杉謙信・松平元康・羽柴秀吉
  - SR（11人）：真田幸村・直江兼続・伊達政宗・本多忠勝・明智光秀・石田三成・島津義弘・長宗我部元親・加藤清正・立花宗茂・竹中半兵衛
  - R（14人）：黒田官兵衛・毛利元就・前田慶次・北条氏康・福島正則・山本勘助・最上義光・朝倉義景・斎藤道三・六角義賢・尼子晴久・大友宗麟・龍造寺隆信・毛利輝元
  イラスト（アイコン・バストアップ・必殺技）は `assets/heroes/` の WebP。
- **ガチャ**（無料のみ。課金・決済なし）：「🎴 ガチャ」から券1枚で1回。排出率は SSR 6%・SR 30%・R 64%。
  券は初回に3枚、2ウェーブごとのクリアで1枚、ボス撃破で1枚。同じ武将を引くと★が増え、攻撃が少し上がる（最大★5）。
- 結果は**確定 → 券を減らす → 保存 → 表示**の順。再読み込みしても結果も券の枚数も変わらない（引き直し不可）。
- **配属**：塔のパネルの「👤 武将配属」、または部隊のパネルの「👤 武将」から。同じ武将は1か所だけ。
  武将ごとに常時効果と必殺技が異なり、塔なら攻撃・射程・支援、部隊なら兵士の攻撃・防御・攻撃速度に効く。
- 必殺技は配属先のパネルから（ウェーブ中・部隊は道に出ているとき）。再配属しても再使用待ちはリセットされない。
- 部隊が全滅・解散すると、武将は死亡せず未配属に戻る。
- 保存（localStorage `worldDefense.warlords.v1`）：所持武将（枚数）・ガチャ券・ガチャ履歴・最後に配属した武将。
  「最初から」でも所持武将と券は残る。壊れた保存データでも起動（初回の券は配り直さない）。
- 数値は `src/index.template.html` の `WARLORDS`（能力）/ `GACHA`（排出率・券）/ `HERO_RULES`。

## 兵士部隊・永久死亡・成長（v8）

塔に配属する「武将」とは別のシステムです。

- **雇用・配置**：兵種ボタン（足軽・槍兵・弓兵。1部隊5人）を選んで**道をタップ**。中心線に合わせて配置。
  草地・マップ外・入口付近・城の直前・ほかの部隊の近くには置けない。道に出せるのは4部隊、保有は8部隊まで。
- **兵士は1人ずつ個別に管理**（ID・兵種・HP・攻撃・防御・Lv・経験値・戦闘数・撃破数・生存ウェーブ数・称号・戦歴）。
- **永久死亡**：HP0で戦死。ウェーブ終了・レベルアップ・補充・編成のどれでも復活しない。全員戦死で部隊は全滅・消滅し、自動で再出撃しない。
- **成長**：攻撃・撃破・ウェーブ生存で経験値。レベルアップで最大HP・攻撃・防御が上がる（現在HPは回復しない）。
  ウェーブ終了時のHP回復は最大HPの20%だけ。
- **称号**：新兵 → 熟練兵（3ウェーブ生存）→ 歴戦の兵（7）→ 百戦錬磨（15）→ 英雄（20＋撃破30）。小さな攻撃・防御ボーナス。
  5人中4人が戦死して1人残ると「最後の生存者」（小さな士気ボーナス・戦歴に記録）。
- **撤退**：戦闘中は3秒かかり、その間も攻撃を受ける（足止め・攻撃はしない）。完了すると待機部隊になり、次のウェーブから再配置できる（費用なし）。ウェーブ間は即座に待機。
- **再編成（ウェーブ間のみ）**：「📋 編成」から、同じ兵種の部隊への移籍・新しい部隊への移籍・新兵補充（1人分の費用）。
  所属は兵士側の1か所だけで管理するので、同じ兵士が複数部隊に入ることはない。レベル・称号・経験値は引き継ぐ。
- **戦闘**：足軽は2体、槍兵は3体まで足止め（生存者数が上限）。1体を止められるのは最長6秒で、その後は突破される。
  騎兵は止められない。弓兵は遠距離から兵士と塔を攻撃する（v12 で塔は耐久制に）。
- 時間はすべて共通のゲーム時間で進み、停止中・ウェーブ間は止まり、x2で2倍速。攻撃間隔は余りを持ち越すのでフレームレートで回数が変わらない。
- 「最初から」で兵士・部隊・経験値・戦歴を初期化。戦闘の途中保存はしない（武将の所持情報の保存はそのまま）。
- 数値は `src/index.template.html` の `SQUAD_RULES` / `SOLDIER_TYPES` / `TITLES` / `ENEMY_VS_UNIT`。
- 戦国武将を部隊に配属できる（上記）。
