# world-defense
Tower Defense Game

ブラウザで遊べるタワーディフェンス。配布物は画像込みの単一ファイル `index.html` です
（GitHub Pages ではこのファイルをそのまま公開します）。

開発状況と今後の計画は [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md) にまとめています。

## 終盤の装備の入手（v53）

- **🔥 爆炎の鉄砲**：天下統一（全国68か国の制覇）の報酬で1つもらえる（ロック済み）。小判では作れない。
  - 天下統一の結果画面とお知らせで伝える。以前に天下統一した保存データには、次の起動で1つ渡す。
  - 1回だけの報酬。売ったり手放したりしても、もう一度はもらえない。
  - 倉庫が満杯でも受け取れる（裏ボスの報酬と同じく、倉庫の枠とは別）。保存できなければ渡さず、次の起動で渡す。
  - 爆発の効果は天下統一の後に働く（裏ボスの討伐は要らない）。
- **👥 幻影の指輪**：最後の裏ボス（零式・天魔機神）を倒すと、「🎒 装備倉庫」で小判2,000両で作れる。終盤の解放の前でも作れて、影分身の効果も働く。
- 光刃・村正と雷神の槍は今までどおり（終盤の解放後に小判2,000両）。
- 保存：天下統一の報酬を受け取った印は `forge.bossRewards.tenka`。以前の保存データはそのまま読める。
- `node tools/test-endgame-gear.mjs` で確認できる。

## 乱入する裏ボスと八玉（v62）

- 通常の防衛戦の**ウェーブ50から**、1ウェーブに **2%** の確率で、ウェーブの途中に裏ボス「👹怨霊・玉梓」が乱入する（修練場・攻城戦では出ない）。
  - 同じウェーブの大将の6倍のHP・2.5倍の攻撃。紫の妖気をまとい、頭の上に「⚠裏ボス」と出る。
  - **怨念の波動**：8秒ごとに、周りの部隊をまとめて攻撃する（1.5秒前に点線の輪で予兆）。
  - 逃げずに城を目指す。城にたどり着かれると**ハート -3**（玉はもらえない）。
- 倒すと**八玉**（仁・義・礼・智・忠・信・孝・悌）を1つ。持っていない種類が出やすい（持っている種類の3倍）。大将のガチャ券は出ない（報酬は八玉だけ）。
- **読み込み直しても戦いは避けられない**：乱入した瞬間に保存する。決着がつく前に閉じると、そのウェーブの始めに戻り、同じウェーブで必ず乱入する（「途中保存」の表示でも知らせる）。倒すか城にたどり着かれると印は消える。「最初から」やり直すとなくなる。
- 「🎒 装備倉庫」に「📿 八玉」タブ：集めた種類（n/8）と、種類ごとの数。8種類そろえたときの交換は次の段階で追加する。
- 確率・強さ・波動・玉の出やすさは `INTRUDER` の設定で調整できる。確認用（`?debug`）では乱入しない（`WD_DEBUG.intruderApi.setRng` で出せる）。
- 保存：`forge.gems`（八玉の数）、防衛戦の途中保存の `defense.intruder`（未決着の乱入）。以前の保存データはそのまま読める。
- `node tools/test-intruder.mjs` で確認できる。

## 乱入する特別な敵：ラッキー足軽・黄金足軽（v61）

防衛戦（ウェーブ3から）と修練場（1ウェーブ目から）で、ウェーブの途中に低い確率で1体だけ現れる。光って見え、頭の上に残り秒数が出る。
- **🍀 ラッキー足軽**（1ウェーブ 4%）：12回攻撃すると倒せる。倒すと、出撃中の兵士それぞれが「次のレベルまでの経験値」の半分をもらう（1ウェーブの上限の対象外。レベルが高くても同じ割合）。9秒で逃げる。
- **💰 黄金足軽**（1ウェーブ 3%）：20回攻撃すると倒せる。倒すと小判（300＋ウェーブ×5両、±20%、上限5,000両）。すぐ保存される。10秒で逃げる。
- どちらも、どんなに強い攻撃でも1回で HP が 1 しか減らない（会心・特殊能力・必殺技も同じ）。数で攻めるのが近道。部隊に足止めされず、兵士・塔・城を攻撃しない。
- 時間切れか、城まで走り抜けると逃げる（報酬なし・城のハートは減らない）。足止め（停止）していても時間で逃げる。水攻めの足止め・武将の停止で逃げるまでの距離をかせげる。
- ウェーブの途中で読み込み直すと、今までどおりウェーブの始めに戻る（特別な敵は残らない）。倒して得た小判は保存済みのまま。
- 確率・硬さ・逃げる秒数・報酬は `RARE` の設定で調整できる。確認用（`?debug`）では出ない（`WD_DEBUG.rareApi.setRng` で出せる）。
- 保存データの形は変えていない。
- `node tools/test-rare-monsters.mjs` で確認できる。

## 書の装備（v57）

- 能力値の書（攻撃・防御・体力・射程）と特殊能力の書（🌟超秘伝書・伝説の特殊能力の書）は、**装備のように付け外しする**。使ってもなくならない。
- 兵士1人に**4冊まで**。付けた書は**全部効く**（同じ種類は足し算）。兵士がもともと覚えている伝説の能力値（有効な1つ）とも足し合わせる。
- 付け外しは「🎒 装備倉庫 → 📜 スキルの書」の「装備する…／外す」か、兵士の「装備」画面の「📚 書（n/4）」から。戦闘中はできない。
- 名簿の兵士の札に「装備している書（n/4・全部効く）」を出す。
- 装備していた兵士が戦死・引退・解散すると、書は倉庫に戻る。同じ書を2人に付けることはできない。
- スキルの書（「治療上手」などのスキルを残した書）は今までどおり、使うと習得して書はなくなる。
- 以前に使った能力値・特殊能力の書で覚えた能力は、そのまま残る。
- 保存：書の `owner`（装備している兵士）。以前の保存データはそのまま読める。
- `node tools/test-super-books.mjs` で確認できる。

  - 🛡️防御の書：防御 +1〜100 か +1〜20%

- レベルアップで伝説の能力を習得するのは、今までどおり終盤の解放後だけ。終盤の特殊装備も今までどおり。

## 終盤：伝説の兵士（v51・試作）

天下統一（全国68か国の制覇）と三大裏ボスの討伐で解放される、やり込みの最終目標。強すぎる兵士が生まれてもよい（意図的な「ぶっ壊れ」）。解放前の序盤〜中盤は今までと同じ。
- **伝説の能力**：解放後、兵士がレベルアップすると12%の確率で1つ習得する。数値は習得したときに抽選して固定。
  - 能力値：攻撃 +1〜100／+1〜15%、防御 +1〜100／+1〜20%、最大HP +10〜500／+1〜25%、射程 +1〜30／+1〜15%。何個でも覚えるが、有効にできるのは1人1つ（名簿で切り替え）。
  - 特殊能力（数の上限なし・重ねると足し算）：🗡️貫通ビームサーベル（一直線上の敵すべて）・⚡連鎖雷撃（周りの敵へ4回まで）・💥爆炎斬（周りに範囲ダメージ）・👥影分身（確率で同じ威力の追加攻撃）。防衛戦・攻城戦・修練場で発動し、光の刃・稲妻・爆発・分身の演出が出る。追加の攻撃からは発動しない（無限に連鎖しない）。演出は数に上限を設けて軽くした。
  - 通常のスキル・職業スキル・ネームド兵士の固有能力はそのまま。
- **終盤の特殊装備（試作）**：光刃・村正（刀・ビーム）／雷神の槍（槍・連鎖雷撃）／爆炎の鉄砲（鉄砲・爆発）／幻影の指輪（装飾品・影分身）。解放後、「🎒 装備倉庫」で小判2,000両で作れる（v53から：爆炎の鉄砲は天下統一の報酬、幻影の指輪は天魔機神の討伐で作れる）（正式版では最終盤の素材を集めて錬成する予定）。秘伝錬成からは出ない。図鑑には入れていない（試作）。
- **指導員として引退**（Lv100から・終盤の解放とは関係なく最初から使える）：名簿の「🎓 指導員に」から。Lv99以下は「🎓 指導員に（Lv100〜）」と表示して押せない。Lv100以上ならいつでも（Lv200・Lv1000でも）引退できる。主人公は引退できない。
  - 習得したスキル（通常・固有・職業・秘伝）か伝説の能力を1つ選び、確認のうえ引退。兵士は部隊から外れ、戦闘に戻れない（戻せない）。ネームド兵士・武将の専用の能力は残せない。
  - 秘伝スキル（スキルの書で覚えるスキル）は今までの「スキルの書」として、ほかは「伝承の秘伝書」（数値もそのまま）として残り、別の兵士に使える（1冊なくなる）。伝説の能力の書を使えるのは終盤の解放後。
  - 名簿の「指導員」タブに名前・職業・引退レベル・残したスキルを記録。
  - 引退・秘伝書の使用は、兵士と武将の保存データを先行ログでまとめて確定する。保存できなければ取り消す（兵士が消えるだけ・書が二重になる、は起きない）。
- 伝説の能力（能力値・特殊能力）と終盤の特殊装備の効果は、終盤の解放後だけ働く。
- **試作の確認**：`index.html` の `<head>` に `<script>window.WD_PREVIEW=true</script>` を入れた試作版だけ、メニューに「🧪 試作：終盤」が出る（解放の切り替え・資金・能力を授ける）。公開版には出ない。`?debug` では `WD_DEBUG.legendApi.setForce(true)`。
- 保存：兵士の `legend`、秘伝錬成の `legendBooks`・`lseq`・`mentors`。以前の保存データはそのまま読める（範囲外の値は捨てる）。
- `node tools/test-legend.mjs` で確認できる。

## 装備をまとめて表示（v47）

「🎒 装備倉庫」を、1行ずつの一覧にして見やすくした。
- 倉庫にある同じ装備は1行にまとめて「南蛮胴 ×5」のように表示する（ロック中のものは別の行）。装備中のものは持ち主ごとに1行（👤 装備者）。
- 行にはアイコン・品質・名前・性能・個数。行を押すと開いて、装備できる職業・倉庫の個数と操作を出す：
  「装備させる…（1個）」・「ロックする（n個）」（まとまりごと）・「1個売却」・「n個まとめて売却」（確認画面あり）。
- 売却モードでは行ごと（まとめた個数ぶん）選ぶ。品質ごと・表示中すべてを選ぶボタンは今までどおり。

## 自由転職・職業スキル（v30）

兵士は Lv30 から、無料で何度でも好きな職業に転職できる。主人公も一般の兵士も同じ。
- **職業（14種。v49 で騎馬の上級職4つを追加）**：足軽・槍兵・弓兵・鉄砲兵・騎兵・衛生兵（基本職。兵種そのまま）と、上級職の
  侍（足軽の動き・攻撃+15%・防御+15%・HP+10%）・忍者（騎兵の動き・攻撃間隔×0.85・防御−10%）・
  剣豪（足軽の動き・攻撃+35%・防御−10%）・僧兵（槍兵の動き・防御+25%・HP+15%・攻撃−15%）。数値は `JOBS`。
- **操作**：主人公育成画面の「🔄 転職」、または兵士名簿の各兵士の「🔄 転職」。職業ごとに特徴・能力補正・熟練度・職業スキル・
  転職したときの能力（今→転職後、▲▼）を表示。戦闘中（防衛のウェーブ中・攻城戦・修練場の挑戦中）は転職できない。
- **引き継ぐもの**：ID・レベル・経験値・名前・戦歴・ステータスポイント・習得したスキル。一度なった職業には Lv に関係なくいつでも戻れる。
  転職の履歴（最近20件）と、なったことのある職業を記録。部隊の兵種は一番多い兵種に合わせる（混成部隊と同じ）。
- **熟練度**：職業ごとに 0〜10。今の職業で経験値を得たときだけ同じ量が増える（転職しただけでは増えない）。

## 修練場（v29）

強い敵と繰り返し戦って、兵士と主人公を育てる戦場。通常の防衛戦20ウェーブ・攻城戦・領土はそのまま。
- **遊び方**：メニューの「⚔️ 修練場」→ 難易度を選ぶ（上級が最初から選ばれている）→「挑戦する」→ 部隊を配置して「ウェーブ開始」。
  1回の挑戦は10・20・30・50・100ウェーブから選択（既定10、選択は保存）。無限は回数制限なしで負けるか撤退するまで。敵Lvは選択した回数で各難易度の最終Lvまで上がる。5ウェーブごとの最後に中ボス、10ウェーブごとの最後に大将。挑戦中の回数変更は不可。挑戦中は画面に「修練場」の帯（ウェーブ・敵Lv・城HP・獲得経験値・撤退ボタン）。
- **難易度と敵レベル**：初級 Lv1〜30、上級 Lv30〜100、超級 Lv100〜500、無限 Lv20 から1ウェーブごとに +12%。ウェーブごとに敵Lvが上がる。敵の頭上に「Lv」、中ボス・大将は赤い札。
  敵レベル L で HP（×1+0.06L）・攻撃（×1+0.012L）・防御（+0.1L）・速さ（最大+35%）・数が上がり、槍兵・弓兵の割合も増える（Lv100 を超えた分はゆっくり）。一撃で減る HP は最大HPの6割まで。数値は `TRAINING`。
- **通常の防衛戦との関係**：始めるときに通常の防衛戦のウェーブ・城HP・ゴールド・塔を控え、終わったら元に戻す（修練場で建てた塔・強化・被害はなくなる。売却はできない）。修練場の城HP は20。負けても通常のゲームオーバーにはならない。
  挑戦中は攻城戦・「最初から」はできない。ガチャ券・領土・反撃・武将の負傷の回復は動かない。
- **経験値（修練場）**：敵レベル L の単位 `6 + 2L`。
  - 攻撃：敵の価値（単位 × 敵の種類の倍率）× 0.7 を、実際に減らしたHPの割合で（倒れた敵への攻撃・残りHPを超える分は数えない）
  - 撃破：敵の価値 × 0.3（1回だけ）
  - 治療：実際に回復したHP ÷ 相手の最大HP × 単位 × 0.6（満タンの味方は回復しないので0）
  - 防御：実際に受けた＋防御で減らしたダメージ ÷ 自分の最大HP × 単位 × 0.4
  - 生存：ウェーブを生き延びると 単位 × 1.5（1ウェーブ1回）
  - クリア：選択した全ウェーブをクリアすると、戦った生存兵に 最後の敵Lv の単位 × 6
  - 1ウェーブの戦闘で得られる上限は `70 + 12L`（通常は70）。
  - 模擬（上級・4部隊×10人・塔6基、ウェーブの合間に治療）：Lv30 は1回のクリアで平均 +2.6Lv、Lv50 は +1.4Lv、Lv100 は +0.7Lv。
- **通常の防衛戦・攻城戦の経験値**：これまでの値のまま（攻撃1・撃破6＋敵の報酬の半分・治療2・生存20）。防衛戦で敵の攻撃を受け止めると +1 を追加（槍兵・足軽も育ちやすく）。
- **報酬**：経験値と少しのG（クリアしたウェーブ × 10 × 難易度の倍率、クリアで +50 × 倍率）。撤退・敗北ではクリアのボーナスなし。報酬は1回だけ。
- **戦死**：ふだんどおり。主人公は Lv1 から再出発（その戦いからは外れる）、ほかの兵士は永久。
- 結果画面に、各兵士の Lv の変化・戦闘の経験値・クリアの経験値。記録（最高ウェーブ・クリア回数）は `worldDefense.training.v1`。
- `node tools/test-training.mjs` で確認できる。

## 主人公・無限育成（v28）

自分だけの一人の兵士を、レベルの上限なく育て続けられるようにした。既存の防衛戦・攻城戦・領土・武将・兵士の育成はそのまま。
- **主人公**：兵士名簿の「👑 主人公にする」か、メニューの「👑 主人公」で生存兵から一人を選ぶ（いつでも変えられる）。
  保存するのは兵士のIDだけ（`worldDefense.soldiers.v1` の `heroId`）。名前・レベル・スキル・戦歴はその兵士のまま。名前に 👑、戦場では頭上に金色の王冠。
- **レベルの上限なし**（一般の兵士も）。必要経験値は Lv30 まで今までどおり、その先は `+ (Lv-30)^1.5` ずつ多くなる。
  能力の伸び（`growthLv`）は Lv30 まで今までどおり、Lv30〜100 は 1/4、Lv100 を超えた分は平方根でゆっくり伸びる（Lv1000でも有限）。
- **ステータスポイント**：レベルが1上がるごとに3。得た数は (Lv−1)×3 で決まり、保存するのは振った数だけ（二重には増えない。過去のレベルの分も自動であり）。
  効果は 振った数 p に対して `max × p ÷ (p + 100)`：攻撃 +100% まで（与えるダメージ）、防御 +100% まで（受けるダメージの軽減）、速さ +50% まで（攻撃・治療の間隔、攻城戦の進軍）、距離 +30% まで（射程・治療の距離）。HP はこれまでの成長のまま。
- **スキル20枠**：習得したスキル（`learned`、数の上限なし）と、装備しているスキル（`skills`、20個まで）を分けた。効果は装備しているスキルだけ。
  Lv5・15 に加えて Lv40 から 20 レベルごとに通常スキル、Lv30・100・200… で固有スキルの機会。空き枠があれば自動で装備し、主人公は育成画面で付け外しできる。
- **主人公の戦死**：消えずに Lv1 から再出発。経験値0・ポイントの振り分けを初期化。習得スキル・装備・スキルのレベル・名前・戦歴は残り、戦死回数 +1、過去最高レベルを記録。
  その戦い（防衛戦のウェーブ・攻城戦）からは外れ、経験値や生存・勝利の報酬は受け取らない。次の戦闘から同じ部隊で戦う。すぐ保存するので、読み込み直しても元のレベルには戻らない。
  一般の兵士の戦死はこれまでどおり永久。
- **育成画面**（「👑 主人公」）：画像・兵種・Lv・経験・HP・攻撃・防御・速さ・距離・未使用ポイント（＋／＋10）・スキル装備 n/20・出陣・撃破・戦死回数・過去最高Lv。
- 将来の拡張用：スキルのレベル（`skillLv`）は保存だけしている。ジョブ・装備・アイテムは未実装（再出発の処理 `heroFall` に初期化の場所を用意）。
- `node tools/test-hero.mjs` で確認できる。

- 攻城戦で新しい国を取ると、50%の確率で**隣の敵国が反撃**してくる。狙われるのは境目の領土（自国以外で、まだ取っていない国と隣り合う国）。

  その前に**ゲームオーバー**になるとその国を奪われ、特産の効果も消える（また攻略できる国に戻る）。
- 「最初から」でやり直しても反撃は続く（奪われもせず、撃退にもならない）。反撃中は新しい国を攻められない（演習はできる）。
- 反撃は `worldDefense.conquest.v1` の `counter` に保存。数値は `COUNTER`（確率・守るウェーブ数・報酬）。

## 清洲城の攻略（v18・Phase 5）

- 攻城戦の相手は城ごとのデータ（`NPC_CASTLES`）になった。最初の城は**清洲城（尾張）**（耐久1600・防衛塔4基・守備兵17人）。
  城の並び `CASTLE_ORDER` の、まだ占領していない最初の城が攻略目標になる（7か国へ広げるときは城を足す）。
- 攻城編成の画面に攻略目標（城名・国・耐久・塔・守備兵・報酬・占領状況）を表示。出陣ボタンにも城の名前を出す。
- 勝利すると**占領**し、保存する（キー `worldDefense.conquest.v1`：城ごとの占領・挑戦回数・勝利数）。
  - 初めて攻め落としたときだけ報酬（清洲城：🎴 ガチャ券 +3）。
  - 占領済みの城は「演習」として何度でも攻められる（報酬・占領なし。経験値・戦死・負傷はふだんどおり）。
  - 撤退・敗北では占領しない（挑戦回数だけ増える）。
- 結果画面に占領の知らせと報酬を表示する。

## 攻城戦（v17・Phase 4 基本システム）

- 「⚔️ 攻城編成」画面の「⚔️ 出陣（攻城戦）」で始める（防衛のウェーブ中は不可）。防衛戦の状態はそのまま止まり、終わると戻る。
- 防衛戦の地図を使い、左から味方が進軍、右端の城がNPCの城（耐久1600）。
  - NPC側：防衛塔4基（弓2・鉄砲・大砲）と守備隊（足軽・槍兵・弓兵・大将の赤い兵）。
- 第一部隊から**10秒ごとに出撃**し、自動で戦う。進軍の速さは部隊で一番遅い兵に合わせる（騎兵だけの部隊は速い）。
  - 守備隊の手前で止まって戦い、届く塔や城を攻撃する。衛生兵は攻城の部隊を回復する。攻城編成の武将は部隊の攻撃・防御を上げる。
- **勝利**：城の耐久を0にする。**敗北**：全部隊が倒れる・全軍撤退・3分の時間切れ。
- 経験値・戦死・負傷は防衛戦と同じ：戦闘中の経験値（1人70まで）＋生還ボーナス20（勝利でさらに+20、撤退はなし）。
  戦死はその場で保存（英霊名鑑にも）、部隊が全滅すると武将は負傷。結果は1回だけ保存する。
- 数値は `src/index.template.html` の `SIEGE_BATTLE`。占領・NPC城の攻略の完成は Phase 5。

## 兵士の育成・命名・スキル（v13）

- 兵士は1人ずつ個別IDで管理し、**ゲームをまたいで残る**（保存キー `worldDefense.soldiers.v1`）。
  - 保存するのは「ウェーブをクリアした時点の生存兵」。新しいゲーム（最初から・再読み込み）では待機中・HP満タンで戻る。
  - 戦死はその場で保存データから外す（再読み込みしても復活しない）。クリアしていないウェーブの経験値は残らない。
- 経験値：攻撃・撃破（戦闘中は1人1ウェーブ70まで）＋ウェーブを生き延びた生存ボーナス20（1ウェーブ1回だけ）。最大Lv30。
- Lv5・Lv15：兵種に合うスキルをランダム習得／Lv10：名前を付けられる（10文字まで・後から変更可）／Lv20：精鋭兵（小さな能力ボーナス）／Lv30：30%で固有スキル。スキルは最大3つ。
  - 槍の達人（攻撃+12%）・鉄壁（被ダメージ-10%）・連続攻撃（15%で追加攻撃）・弓回避（遠距離の被ダメージ-25%）・生存本能（HP3割未満で撤退を試みる・成功率60%）・敵将狙い（大将へ+30%）・速射／遠矢（弓兵）
  - 固有：不屈（足軽）・槍衾（槍兵）・百発百中（弓兵）。城攻め名人は将来の攻城戦用（まだ習得しない）
  - Lv10を超えた分の能力の伸びは半分（強くなりすぎない）
- 部隊パネル（と編成画面）の「🩹 治療」：ウェーブの合間に、部隊の生存兵のHPを満タンにする（雇用費×60%×減ったHPの割合／人。戦死者は対象外）。
- 生存本能で撤退した兵士はそのウェーブの間だけ戦場を離れ、次の戦闘から使える。
- 「🪖 兵士」で兵士名簿（名前・兵種・Lv・経験値・スキル・戦歴、Lv10以上は命名）と**英霊名鑑**（名前付きの兵士の戦死記録。復活はできない）。
- **武将の負傷**：配属先の塔が破壊される・部隊が全滅すると、武将は死なずに負傷。その後3ウェーブは塔にも部隊にも配属できず、4ウェーブ目から復帰。
  残りはウェーブをクリアしたときだけ減る（負けた・やり直したウェーブでは減らない）。負傷は武将の保存データに残る。
- 数値は `src/index.template.html` の `SQUAD_RULES` / `SOLDIER_SKILLS` / `RANKS` / `HERO_RULES.injuryWaves`。

## 敵兵の攻城（v12）

- 結果は**確定 → 券を減らす → 保存 → 表示**の順。再読み込みしても結果も券の枚数も変わらない（引き直し不可）。
- **配属**：塔のパネルの「👤 武将配属」、または部隊のパネルの「👤 武将」から。同じ武将は1か所だけ。
  武将ごとに常時効果と必殺技が異なり、塔なら攻撃・射程・支援、部隊なら兵士の攻撃・防御・攻撃速度に効く。
- 必殺技は配属先のパネルから（ウェーブ中・部隊は道に出ているとき）。再配属しても再使用待ちはリセットされない。
- 部隊が全滅・解散すると、武将は死亡せず未配属に戻る。
- 保存（localStorage `worldDefense.warlords.v1`）：所持武将（枚数）・ガチャ券・ガチャ履歴・最後に配属した武将。
  「最初から」でも所持武将と券は残る。壊れた保存データでも起動（初回の券は配り直さない）。
- 数値は `src/index.template.html` の `WARLORDS`（能力）/ `GACHA`（排出率・券）/ `HERO_RULES`。

## 兵士部隊・永久死亡・成長（v8）

塔に配属する「武将」とは別のシステムです。

- **雇用・配置**：兵種ボタン（足軽・槍兵・弓兵。v41 から1部隊10人で雇用）を選んで**道をタップ**。中心線に合わせて配置。
  草地・マップ外・入口付近・城の直前・ほかの部隊の近くには置けない。道に出せるのは4部隊、保有は8部隊まで。
- **兵士は1人ずつ個別に管理**（ID・兵種・HP・攻撃・防御・Lv・経験値・戦闘数・撃破数・生存ウェーブ数・称号・戦歴）。
- **永久死亡**：HP0で戦死。ウェーブ終了・レベルアップ・補充・編成のどれでも復活しない。全員戦死で部隊は全滅・消滅し、自動で再出撃しない。
- **成長**：攻撃・撃破・ウェーブ生存で経験値。レベルアップで最大HP・攻撃・防御が上がる（現在HPは回復しない）。
  ウェーブ終了時のHP回復は最大HPの20%だけ。
- **称号**：新兵 → 熟練兵（3ウェーブ生存）→ 歴戦の兵（7）→ 百戦錬磨（15）→ 英雄（20＋撃破30）。小さな攻撃・防御ボーナス。
  4人以上が戦死して1人だけ残ると「最後の生存者」（小さな士気ボーナス・戦歴に記録）。
- **撤退**：戦闘中は3秒かかり、その間も攻撃を受ける（足止め・攻撃はしない）。完了すると待機部隊になり、次のウェーブから再配置できる（費用なし）。ウェーブ間は即座に待機。
- **再編成（ウェーブ間のみ）**：「📋 編成」から、同じ兵種の部隊への移籍・新しい部隊への移籍・新兵補充（1人分の費用）。
  所属は兵士側の1か所だけで管理するので、同じ兵士が複数部隊に入ることはない。レベル・称号・経験値は引き継ぐ。
- **戦闘**：足軽は2体、槍兵は3体まで足止め（生存者数が上限）。1体を止められるのは最長6秒で、その後は突破される。
  騎兵は止められない。弓兵は遠距離から兵士と塔を攻撃する（v12 で塔は耐久制に）。
- 時間はすべて共通のゲーム時間で進み、停止中・ウェーブ間は止まり、x2で2倍速。攻撃間隔は余りを持ち越すのでフレームレートで回数が変わらない。
- 「最初から」で防衛の途中保存・塔・軍資金を初期化。保存済みの生存兵の育成・所持武将・装備は残る。戦死した兵士は復活しない。
- 数値は `src/index.template.html` の `SQUAD_RULES` / `SOLDIER_TYPES` / `TITLES` / `ENEMY_VS_UNIT`。
- 戦国武将を部隊に配属できる（上記）。

### 保存と能力補正の回帰確認

`CHROMIUM_PATH=/usr/bin/chromium node tools/test-save-regressions.mjs` で、倉庫満杯時の裏ボス初回装備、保存途中の失敗、信玄の人数上限、混成部隊の衛生兵補正を確認できます。

- 通常の倉庫上限は300個ですが、三大裏ボスの初回限定装備は上限を超えても保持します。旧版で受領済みフラグだけが残った限定装備も読み込み時に復元します。
- スキルの書の消費と習得は `worldDefense.bookTransaction.v1` にまとめて確定します。通常の武将・兵士保存に転記できなかった場合も、この記録を正本として読み込み、次の保存時に転記を再試行します。確定記録そのものを保存できない場合は、習得も消費も取り消してエラーを表示します。
- 武田信玄の人数補正は生存兵5人まで。回復量・回復速度・回復射程の補正は混成部隊でも衛生兵だけが受けます。
