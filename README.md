# WORLD DEFENSE テストプレイ版（戦場試練）

このブランチ（`trial-test-preview`）は、iPhone の Safari で「⚔️ 戦場試練」をテストプレイするための**配信専用のブランチ**です。本番のゲーム（main・GitHub Pages）とは関係ありません。

- 中身：`index.html` 1つ。Draft PR #127〜#140 と Phase 4.7（サバイバルの攻撃スキル育成）の機能を含むテスト用ビルドです（`node tools/build.mjs --test` で作成）。
- 開くURL：<https://raw.githack.com/amazing19731214-gif/world-defense/trial-test-preview/index.html>
  - 最初に raw.githack.com の注意の画面「External Content Notice」が出たら、「Open the page」を押してください。
  - このブランチに push するたびに、GitHub Actions「テスト配信の確認」が、このURLを iPhone 13 相当の WebKit と Chromium で開いて操作し、確かめます。
  - raw.githack.com（無料・登録不要）が、このブランチの `index.html` をそのまま配信します。
  - 本番の公開サイト（amazing19731214-gif.github.io）とは別のオリジンです。
- 保存：このページは、すべてのキーの頭に `wdtest:` を付けた別の保存領域だけを使います。本番の保存データは読まない・書かない・消さない。
- 停止・削除：このブランチを削除すると配信が止まります（raw.githack の短い保存期間のあと見られなくなります）。

- Phase 4 の遊び方：戦闘中に下の兵士の名前（または戦場の兵士）を押すと、その兵士を左下のスティックで動かせます。攻撃と技は自動です。「🤖 全員自動」で全員を AI に戻します。

- Phase 4.2 の遊び方：「⚔️ 戦場試練」の画面の上で「🔥 サバイバル」を押し、兵士を選んで「👑 主人公」を1人決めて開始（ほかの兵士は仲間候補）。主人公1人で始まり、敵を倒してレベルアップすると戦闘が止まって「👥 仲間を1人加入」か強化を選べます。2分30秒で大将が出て、倒せば勝利。
- Phase 4.3：テスト用兵士を準備し直すと「試・剣神」が奥義継承者（奥義書3冊）になります。サバイバルで試・剣神を主人公にすると、右下の「⚔️ 奥義」ボタンで1回だけ奥義を使えます（継承する奥義は兵士名簿の「⚔ 奥義」で変更）。
- v108.4：三方の関で、ステータス「速さ」が歩く速さに入り、操作中の兵士は1.25倍で歩きます。兵士の絵が大きくなり、斬撃・矢・弾が光ります（テスト用兵士は準備し直すと「速さ」のポイント入り）。
- Phase 4.4：サバイバルで、倒した敵が青い経験値コインを落とします。主人公が近づくと吸い寄せて拾い、上の横長の経験値ゲージが伸びます（仲間は拾わない）。
- Phase 4.5：戦場試練（三方の関・サバイバル）に効果音が付きました。画面に触れると音が出ます。撤退の右の「🔉 中」で音量（大・中・小・消音）を変えられます。
- Phase 4.6：サバイバルは大将を倒すと宝箱 →「次の面へ進む」で次の面へ。面が進むほど敵が強くなり、5面ごとに鬼大将。主人公が倒れるまで続きます。
- Phase 4.7：サバイバルの主人公は攻撃スキルを1つ持って始まります（左上のアイコン）。レベルアップの3択で「強化（Lv○→Lv○）」か「新しい攻撃スキル」を選べます（8種類・6種類まで・Lv5まで）。雷撃Lv5＋真空斬Lv5、火炎輪Lv5＋旋風斬Lv5 で、宝箱からスキル進化（雷神剣・紅蓮旋風）。スキルはその挑戦の間だけです。

**マージしないでください。** このブランチは main とつながっていない（履歴が別の）配信専用のブランチです。
